# 当前数据对不同深度和参数组合的约束

本轮完成先验／后验分析，使用已验收 `nuts-original-095-search` 的全部 4×1000 正式状态，
不重新采样或正演。结果支持下一步做先验标准差 0.1→0.2 km/s 的敏感性对照；本轮先完成
只读分析与是否值得继续的判断，没有启动第二轮采样。

## 主要结果

**不能笼统地说“浅部或深部没有约束”。单层细节与深度段平均速度的约束差别很大。**

- 第一层覆盖 0–2.741 km，后验标准差约 0.0243 km/s，为先验的 24%；并非完全不受约束。
- 2.741–6.726 km 的密集薄层，单层标准差比约 0.946–1.043，收缩很少。
  45 个参数中有 25 个标准差比≥0.9；此阈值只作描述，不是“可分辨／不可分辨”的判据。
- 较厚的 28.382–50.555 km 两层标准差比约 0.312 / 0.258，收缩较明显。
- 139.283–208.925 km 层为 0.810，半空间参数为 0.686，约束相对有限；半空间是单个常数，
  不能把图上延伸至 350 km 的常数区间解读为每个深度都得到独立分辨。

深度段平均值采用原层厚与指定区间的交叠长度加权。当前先验各层独立，因此平均值的先验
方差为 `sum(w_i² * prior_var_i)`；后验方差包含全部交叉协方差，不能忽略参数相关性。

| 深度段 km | 平均 Vs 的先验 SD | 后验 SD | 后验／先验 SD |
|---|---:|---:|---:|
| 0–3 | 0.09149 | 0.02151 | 0.235 |
| 3–10 | 0.02311 | 0.01475 | 0.638 |
| 10–20 | 0.04124 | 0.01409 | 0.342 |
| 20–50 | 0.05617 | 0.00903 | **0.161** |
| 50–100 | 0.06994 | 0.02423 | 0.346 |
| 100–208.925 | 0.07341 | 0.04608 | 0.628 |
| ≥208.925，半空间参数 | 0.10000 | 0.06860 | 0.686 |

SD 单位为 km/s。这些分段是便于描述的统计区间，不是分辨率长度的估计。
分段平均值本身的先验已依赖层划分和独立先验，不能把后验区间完全当作数据单独提供的精度。
新增七个量最大 R-hat 约 1.00324，使用全四链重算，未挑选有利状态。

## 均值偏移和层间补偿

均值偏移以 `(后验均值 - 先验均值) / 先验SD` 表示：

- 第一层约 −1.71；19.225–22.920 km 层约 −3.56。
- 50.555–75.489 km、75.489–139.283 km 两层约 +2.74、+2.08。
- **20–50 km 平均速度的均值几乎不变，但标准差缩小约 84%。** 因此“仍接近参考模型”
  不等于“数据没有约束”；反过来，单看均值偏移也不能判断区间有多可靠。

最强几组相关性为：

| 层顶深度对 km | 后验相关系数 |
|---|---:|
| 28.382 / 36.748 | −0.690 |
| 19.225 / 22.920 | −0.618 |
| 16.611 / 19.225 | −0.607 |
| 139.283 / 208.925 | −0.576 |

负相关说明在当前后验中，一个参数增大时另一个常随之减小，存在补偿。
宽区间平均值可能比各个独立层速度更稳定；这与上表一致，但不证明某个唯一的物理结构。

## 为什么 LM 和 NUTS 的中心曲线接近

当前 LM 使用物理 Vs 的参考阻尼 λ=100，残差为 `sqrt(lambda) * (Vs - Vs_ref)`，
进入目标函数的项是 `0.5 * 100 * sum((Vs - Vs_ref)^2)`。
NUTS 的物理 Vs 高斯先验 σ=0.1 km/s 恰好产生相同的二次惩罚强度。
实现见 `third_party/invLM/src/regularization.cpp`、`src/regularization.cpp` 和 `src/objective.cpp`。

所以二者不是互相独立的“无先验结果”：相似的中心有共同目标结构作为原因。
LM 是点估计，NUTS 中位数并不必然等于 MAP；坐标变换 Jacobian 保证 NUTS 的物理先验正确，
不能拿变换空间的密度峰值直接替代物理 Vs 空间的 MAP。

## 下一步的决定与比较口径

**值得将先验标准差放宽到 0.2 km/s，优先检验那些收缩少的薄层与深部参数。**
保持数据、层界面、参考中心、物性关系、边界及采样策略不变，重新适应初始 GN 和质量矩阵。
重点比较逐层与分段平均值的中位数、区间宽度、预测拟合及边界附近质量，而不是只看整条曲线。

边界仍为参考±0.6 km/s：相对新先验是约±3σ，先验将有更明显的截断，比较时应使用实际
截断先验标准差而不是简单假定正好翻倍。变化的是统计目标，不把该对照当成采样器提速试验。
若同步比较新的 LM，匹配 σ=0.2 的参考阻尼应为 λ=25；旧 λ=100 LM 只能作为原基线展示。

## 限制与复现

收缩比较同时依赖数据似然、模态支持域、模型参数化和固定先验，不能把全部变化归为数据的
独立分辨能力。接近或略大于 1 的标准差比可能包含有限样本波动与非线性后验效应。
本轮没有证明放宽先验后结果稳定；这正是下一项需要回答的问题。

```sh
MPLCONFIGDIR=/tmp/dw-matplotlib python scripts/analyze_crust_constraints.py \
  --run results/nuts-original-095-search --output results/crust-depth-constraints-new
```

脚本核对原验收状态、样本形状、逐层统计及相关矩阵，重新计算实际截断先验方差；
每个分段的样本方差与 `wᵀ Cov(Vs) w` 独立核对。另保存哈希、CSV、JSON、PNG/PDF，
并独立核对输入未变、分位数和分段权重。生产内核、原采样结果及主图保持不变。
