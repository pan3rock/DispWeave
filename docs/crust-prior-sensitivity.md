# 物理 Vs 先验标准差 0.1→0.2 km/s 的敏感性对照

接续 [深度约束分析](crust-depth-constraints.md)，检验弱约束薄层与深部对先验宽度的依赖。
这是统计目标改变后的科学对照，不是采样器提速试验。

## 固定协议

- 基线为已验收 `nuts-original-095-search`；新配置唯一变化是 45 层 `prior_sigma_vs` 从 0.1 改为 0.2。
- 数据、协方差、参考模型、固定层界面、Brocher05、原四初值、seed 20261023、模态支持域不变。
- slice、目标 0.95、合理步长搜索、标准 dense 适应；每链 1000 预热＋1000 正式。
  初始 GN 矩阵按新先验重算，不能复用旧先验的矩阵。
- 四个数值进程并行；单链上限 1800 秒，无中途调参、追加预算或挑链。
- 完整四链要求 49 个量 R-hat≤1.01、bulk/tail ESS≥400，正式无发散、数值失败或树深截断。
  每链预定第 500 个零基正式状态核查两尺度导数，每链选 100 状态做后验预测。
- 物理边界保持参考±0.6 km/s，与全局 [0.5,6] 相交。新先验约±3σ截断，使用实际截断先验的
  标准差解释收缩；边界附近定义为距离上下界不足 0.05 km/s，并同时计算其先验概率。
- 比较逐层与厚度加权分段的中位数、95% 区间宽度、预测拟合和边界附近比例。
  若采样未完整则不汇总比较；若完整但未通过验收，比较仅作诊断。

```sh
python scripts/benchmark_crust_prior.py --reference results/nuts-original-095-search \

MPLCONFIGDIR=/tmp/dw-matplotlib python scripts/compare_crust_priors.py \

```

## 实际结果

**新先验下四链完整验收通过。** 每链 1000 预热＋1000 正式，采样耗时约 531–845 秒，
未触及 1800 秒上限，也没有重试。最大 R-hat=1.00569，最低 bulk ESS=818.4、tail ESS=490.9。
正式期发散、数值失败和树深截断均为 0；共有 87 次合法模态支持域拒绝。
预热发散为 6/5/4/3，数值失败为 2/1/3/0；放宽先验没有消除预热不稳定性。
四个预定状态的两尺度导数核查通过，400 个预测状态全部有效。

新先验截断后的标准差为 0.197316 km/s，约为原来的 1.973 倍。
本轮初始 GN 矩阵的变化已逐链与新先验曲率的解析变化独立核对，不是复用旧矩阵。

- 2.741–6.726 km 的薄层 95% 区间宽度比为 **1.73–2.06**，与先验宽度增加接近。
  这支持此前判断：这些单层细节仍明显依赖参考先验。

## 19.225–22.920 km 层出现明显边界影响迹象

该层物理范围仍为 **[3.06696, 4.26696] km/s**：

| 指标 | σ=0.1 | σ=0.2 |
|---|---:|---:|
| 中位数 km/s | 3.30907 | 3.18147 |
| 逐点 95% 区间 km/s | [3.20329, 3.42626] | [3.08501, 3.31829] |
| 距物理下界不足 0.05 km/s 的比例 | 0 / 4000 | **470 / 4000，11.75%** |

上界附近比例为 0。新链分别为 12.8%、12.7%、11.7%、9.8%，不是只由一条链贡献。
新独立截断先验在上下界附近合计概率只有约 0.327%，其边界附近后验质量显著增多。
该层也是本轮最低 tail ESS 的参数（约 491）。这些迹象要求检查边界敏感性，
但仅靠这次运行还不能量化移除或放宽边界后的后验。

尤其不能把该层区间宽度仅增加约 4.6% 解读为“对先验不敏感”：中位数已移动，
且下尾接近固定下界。区间稳定性与边界作用必须一起判断。

## 数据拟合的变化

基于各自 400 个保存预测状态，后验平均频散曲线的总体 RMS 从 **0.01909** 降至
**0.01802 km/s**。平均观测 χ² 从约 123.1 降至 113.0，预测检验超越比例从 0.515 变为 0.7625；
两者逐点 95% 预测区间均覆盖 121/125 个观测。超越比例不是越大越好，也不是独立验证集评分。

这表明较不同的局部模型细节仍可提供相近量级的数据拟合。不能仅凭稍小的残差选择较宽先验，
也不能据此断言新模型更接近合成目标；目标与反演的界面和物性关系本来就不同。

## 本轮决定

保留 σ=0.1 作为原已验收基线，同时保留 σ=0.2 的完整结果作为敏感性证据，不自动替换主图
或宣称存在唯一最优先验。可以明确报告：薄层细节及部分深部不确定性依赖先验，若干宽区间
平均速度相对更稳定。

**后续已完成下界来源审查，见 [本算例收尾判断](crust-study-closeout.md)。**
下界来自参考速度窗口；仅在需要解释该低速层幅度时才启动单独的边界对照，当前停止追加扫描。
不应同时继续放宽先验和边界，否则难以区分两种作用。本轮未启动新的边界试验。


## 核查与限制

核查完整配置只改先验标准差、起点/数据/边界一致、每链初始 GN 矩阵的变化等于新先验曲率的
解析对角变化、搜索时点、调用数、正式状态和分位数。原样本不重跑，生产内核未修改。
脚本通过语法检查与真实数值运行；完整组的统计另做独立重算。

先验变宽后的后验仍然以固定参数化、物性关系、噪声和有限边界为条件，不是无先验反演。
原 λ=100 的 LM 对应 σ=0.1，不能把它与新 σ=0.2 的差异全部归因于求解算法；本轮不重算 LM。
本地证据在 `results/crust-prior-020/` 与 `results/crust-prior-comparison/`，原推荐结果和主图保留。
