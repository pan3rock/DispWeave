# 地壳参考模型与自由半空间验证

2026-10-23。按用户确认的下一步，先验证常规固定层数 LM 配置，不以修复全部近邻根反例为前置条件。
本轮不修改 C++ 正演、核函数、LM 算法、终止阈值或观测筛选规则。

## 输入与预先确定的配置

使用本地 QEDispInv `ed1b5dd7b449a2b3a27bb8e6581278790f5df8aa` 的
`demo/syn-crustmantle/config.toml` 所指定的 `model_ref=mref.txt`，以及原 `data.txt`。
不读取 `model_data.txt` 来确定参考 Vs、层界面、边界、初值或正则化中心。
这保证本次程序使用的是单独提供的参考文件；不据此断言 mref 在原项目中的生成过程与真值独立。
原始文件副本、SHA256、外部仓库状态、所用程序哈希和运行脚本快照均保存在结果目录。

| 项目 | 本轮设置 |
|---|---|
| 层数与自由参数 | 45 层，全部 45 个 Vs 自由 |
| 几何 | 保留 mref 全部层界面，半空间顶深 208.925 km，以下无限延伸 |
| 全局范围 | Vs ∈ [0.5, 6.0] km/s |
| 局部窗口 | 完整 `vs_width=1.2` km/s，与全局范围取交集 |
| 半空间参考与边界 | 参考 Vs=4.59635；允许 [3.99635, 5.19635] km/s |
| 物性 | Brocher05 派生 Vp/ρ，包含完整链式导数 |
| 正则化 | reference_damping，λ=100，中心为 mref 的 Vs |
| 观测 | 原 125 点，0–3 阶，0.01–0.4 Hz；保持原顺序、全部参与 |
| 误差 | 独立 σ=0.02 km/s，沿用此前明确假设的误差；源数据无误差列 |
| 求解 | 有界 LM、隐式灵敏度、refined Dunkin；最多 200 次，投影梯度阈值 1e-5 |

本例所有参考窗口都落在全局范围内，因此有效边界均为参考值 ±0.6 km/s。
半空间没有观测最大相速度下限，也未被固定。所有层均允许低速结构。

五个初值均只从参考模型构造：参考本身、整体减 0.2、整体加 0.2 km/s，以及
`ref + 0.2 sin(2πz/100)`、`ref + 0.2 cos(2πz/100)`，z 为 km。
后两者按物理深度变化，避免因为浅层节点密集而人为引入逐层交替的高频起伏。
所有初值必须严格处于同一支持域内；不截断或根据正演成败替换初值。
半空间初始值随各初值一起变化。

参数在查看结果前已明确记录。λ=100 对应约 0.1 km/s 的参考偏差尺度，
只是本次确定性惩罚的明确选择，未经过自动选取或误差校准。
这里沿用前轮参考阻尼，而不是将 QEDispInv 的 λ=0.1 原样移植：
原项目的目标缩放、差分正则项、模态权重及误差设置与当前定义不同。
原配置还启用了随机分层，本次固定参考界面，因此不是完整复现其优化实验。

## 结构一致性与数值验证

半空间 Vs 从参考 4.59635 优化到 **4.68607075 km/s**；首层从 3.11421 变为约 2.93892663 km/s。
最大单层相对参考改变量约 0.36210 km/s，低于窗口半宽 0.6；无参数达到上下界。

五个收敛模型之间，最大逐层 Vs 差约 **3.04e-8 km/s**，半空间差约 3.82e-10 km/s；
预测相速度最大差约 1.52e-9 km/s。
以层厚加权、对全部模型对比较的最大 Vs RMS 差为：

| 深度范围 km | 最大模型对 RMS 差 km/s |
|---|---:|
| 0–20 | 1.39e-8 |
| 20–100 | 6.44e-9 |
| 100–208.925 | 7.10e-10 |

这表示本组初值收敛到数值上相同的正则化解，**不是后验可信区间或深度分辨率**。
五个初值的幅度与形状有限，不能据此证明全局唯一性。参考中心、权重与误差仍会影响结果。

每个终态都对全部 45 个自由 Vs 和全部 125 条观测，采用 log Vs 的中心差分
h=1e-5、1e-6，Brocher05 的 Vp/ρ 同步变化。
通过标准仍为 `abs(FD-J) <= 2e-6 + 1e-3*max(abs(FD),abs(J))`；两步长均全部通过，
h=1e-6 的最大归一化误差约 0.00178（通过阈值为 1），没有未解析差分条目。
数据 cost 与参考阻尼 cost 分别由保存的预测和最终 Vs 独立重算核对。

使用保存的配置和观测再次调用 `invert`，23 个模型、预测、轨迹、代价和边界文件
与首次运行逐字一致，记录于 `replay-check.json`。
外部示例输入/统计测试 **7/7** 通过，新增检查参考几何和半空间自由状态、
物理深度初值扰动及按层厚积分的结构差异。核心 C++ 未修改，未重复上轮完整回归或 UBSan。

本次正常配置能够稳定求解地壳案例，支持优先完善常规反演设置的开发顺序。
它与此前 44 层/320 km 或 C 组/固定半空间实验同时改变了多项条件，不能将全部改善
只归因于单一因素。本轮不修改已保留的漏根反例，局部导数检查也不构成根枚举的全域完备性证明。

## 复现与结果文件

```bash
MPLCONFIGDIR=/tmp/dw-mpl python scripts/benchmark_crust_reference.py \
  --source /path/to/QEDispInv --exe build-properties/dispweave \
  --output results/crust-reference-new \
  --vs-min 0.5 --vs-max 6.0 --vs-width 1.2 --start-amplitude 0.2 \
  --sigma 0.02 --regularization reference_damping --lambda 100 --max-iterations 200
```

需要 Python 3.11、NumPy；绘图需要 Matplotlib，可用 `--no-plot` 跳过。
脚本拒绝覆盖旧目录，外部仓库不作修改；只在所有初值收敛且终态 FD 全部通过时返回 0，
存在部分失败则完整保存并返回 4。
本次结果目录为 `results/crust-reference-free/`：

- `inversion.toml`、`observations.txt`、`provenance.json`、原始输入副本与运行脚本快照；
- `initial-*/`、`lm/`、`audit-*/`：所有初值、目标分解、逐层边界、模型、轨迹及完整 FD 数组；
- `summary.json`、`fit-by-mode.json`、`replay-check.json`；
- `comparison.png/.pdf`：完整结构、浅部结构、全部残差；
- `dispersion.png/.pdf`：0–3 阶观测及五组重合预测。

结果是显式参考约束下的固定参数化估计；本轮未输出后验不确定性。
