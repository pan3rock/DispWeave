# 当前合成算例收尾与继续研究的条件

本轮决定：停止继续扫描 NUTS 启发式、先验宽度和速度边界。保留已验收配置与结果，
把局部结构对建模假设的依赖作为结果的一部分。此次只审查已有输入与样本，没有新增正演或采样。

## 下界从哪里来

冻结的原合成示例 `results/crust-target-comparison/config.toml` 使用 `vs_width=1.2`。
当前参考模型流程沿用这个窗口，`scripts/benchmark_crust_reference.py` 的 `reference_config`
将参考速度±半窗口与全局 [0.5,6] km/s 相交。这只说明窗口的来源，原示例的其他设置不等于当前设置。

19.225–22.920 km 层（零基索引 37）的参考 Vs 为 3.66696 km/s，因此范围为
**[3.06696,4.26696] km/s**。在已检查的配置和项目文档中，没有找到专门为该层提供的物理下限依据。
这个下界应解释为参考模型周围的建模窗口，不能直接解释为已知的地质最低速度。

两组各四链、每链 1000 个正式状态，重新从链文件计算：

| 0.010 | 0% | 1.15% |

| 0.050 | 0% | 11.75% |

两组最小样本与下界的距离分别为 0.078925 和 0.002131 km/s；所有保存状态严格位于边界内，
没有发现直接裁剪到下界的样本。较宽先验的四链在 0.05 km/s 邻域中的比例为
12.8%、12.7%、11.7%、9.8%。这是边界作用的迹象，不能量化被边界排除的概率质量。
这些比例依赖邻域宽度，也受相关样本的蒙特卡洛误差影响；不把 4000 个状态视为独立试验。

原始链、输入哈希和重算代码保存在
[本地核查结果](../results/crust-boundary-review/audit.json) 与
[核查脚本](../results/crust-boundary-review/audit.py)。可在仓库根目录执行
`python results/crust-boundary-review/audit.py` 重算。

现有状态全部来自原支持域，不能据此推断放宽边界后的后验，更不能声称宽深度段平均速度
已经通过边界敏感性验证。此前的相对稳定性只针对固定边界下 σ=0.1→0.2 的比较。

## 为什么现在可以停止

- **采样实现与本算例运行已有充分的阶段性证据。** [完整四链验收](nuts-original-095-search.md)
  最大 R-hat 为 1.00352，最低 bulk/tail ESS 为 1695/1990；正式期无发散、数值失败或树深截断，
  导数与预测核查通过。相对原设置，最低 bulk ESS/总评估提高约 2.30 倍。这不等于证明适用于所有问题，
  但没有证据要求继续为本算例添加内核规则。
- **科学限制已经暴露。** [先验敏感性](crust-prior-sensitivity.md) 表明薄层细节和局部速度对比依赖先验；
  较宽先验运行也通过四链验收。局部结果发生变化本身不构成 NUTS 故障证据。
- **逐层追齐目标不是合适的停止标准。** [目标与反演定义](crust-target-comparison.md) 的界面、半空间深度
  和 Vp/ρ 关系不同；当前反演固定 45 层界面并使用 Brocher05，目标是另一套 44 层模型。
  加上数据噪声及有限约束，不能靠继续调采样参数消除这些差异。

因此，当前成果可以用于展示正演、LM 与 NUTS 流程，以及给定模型假设下的不确定性；
不能把每个薄层速度、19–23 km 低速层的精确幅度或单个合成算例的表现作为普遍结论。
原 σ=0.1 基线和主图保留，σ=0.2 作为敏感性证据，不按拟合残差挑选“最佳先验”。

## 何时才值得继续

只有当下一项研究确实需要回答“19–23 km 低速层有多低”时，才做一次单独的边界对照：
先依据独立物理信息确定替代范围与科学上有意义的变化量，固定 σ=0.2 和其余条件，明确比较
局部幅度及宽区间平均值；按既定四链验收标准和有限预算执行。若结果明显变化，就报告边界依赖，
不连续扩范围来追求目标曲线。放宽支持域需要新采样，不能用当前样本重加权恢复域外概率。

若下一目标是通用方法验证，应另设独立算例验证覆盖率与稳健性；若目标是真实数据解释，
优先确认观测误差、参数化和物性关系是否合理。这些都应作为有明确问题的新任务，当前不自动启动。
