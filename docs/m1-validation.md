# M1 正演基线验收

日期：2026-10-21。M1 完成 C++ 正演交付，不包含核函数、似然、LM、HMC 或 RJMCMC。
本报告区分独立物理验证、上游迁移回归和内部一致性测试。

## 实现范围

- C++17 核心库：全固体层状模型校验、可替换正演接口、invLM Dunkin 适配。
- CLI11 命令行、toml11 配置、含版本和模型信息的逐行结果输出。
- 查询可乱序、重复、各阶不同采样；每个请求均有结果行。
- `valid`、`missing_or_unresolved`、`numerical_failure` 三类状态；无效值为 NaN。
- 同频率请求共用一次根枚举；没有跨模型 warm start 和全局可变缓存。
- 缺根不使用 `search_mode` 的渐近备用值，也不静默删行。
- 对极端频厚尺度，在上游样本数量的整数转换前作溢出检查。
- 随库源码依赖、来源哈希检查、CTest、可选安装和性能程序。

当前 `roots_found` 是请求根前缀中找到的数量。没有声明物理上的根全集完备性，
也没有单独的“已证实模态不存在”状态。查询模态编号范围为 0–1023（资源边界）。

## 依赖与修改来源

Eigen 3.4.1、toml11 4.4.0、CLI11 2.4.2 随库提供，无构建期下载、系统包查找、
本机绝对路径或必需 Python 环境。invLM 来源 commit：
`86ad6fa5aaec3f44c6ddcac3d69b27a2f13c2e88`。

本次仅导入频散与求根所需的四个源文件及配套头文件，核函数留到 M2。
`python scripts/verify_vendor.py` 校验 **444 个第三方文件**通过。

发现并修复一个真实问题：原 invLM 的 0.8 Vs 搜索下界可能漏掉低 Vp/Vs
半空间根。本地将 Rayleigh 下界扩展为 0.5 Vs，保留 Love 路径不变。
对于 Vs=0.6、Vp=0.72、rho=2 的半空间，修复前基阶缺失；修复后得到
约 0.449352742970114 km/s，与独立 Rayleigh 方程一致。
原始 invLM 仓库没有修改。

参见 [局部修改说明](../third_party/invLM/PATCHES.md)；清单同时保留原版与本地文件哈希。
没有用经验相速度替换缺根，没有为自动微分重写求根器。

## 构建和实际运行

环境：Linux x86_64，WSL2 内核 6.18.54.1，Intel Core Ultra 9 285H，
GCC 13.3.0，CMake 3.28.3。Release 使用 CMake 默认优化（`-O3 -DNDEBUG`），
没有启用 fast-math。正演基线为单线程。

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
ctest --test-dir build --output-on-failure
```

结果：**10/10 CTest 通过**。

另外将完整所需源码复制到新的临时目录，在受限网络沙箱中重新配置、构建并运行
CTest，同样 **10/10 通过**；安装后的 `dispweave` 成功运行普通模型示例，
输出 7 行、0 行无效。此项证明当前 Linux 主机上无缓存构建与安装可用，
并非所有操作系统或全新 OS 镜像的认证。

Debug 数值检查：

```bash
cmake -S . -B build-check -DCMAKE_BUILD_TYPE=Debug \
  -DCMAKE_CXX_FLAGS='-fsanitize=undefined -fno-sanitize-recover=all -fno-omit-frame-pointer'
cmake --build build-check -j2
ctest --test-dir build-check --output-on-failure
```

结果：**10/10 通过**，没有报告未定义行为。此项不是 AddressSanitizer 或内存泄漏认证。
实际 ELF 依赖仅有标准 C/C++ 运行库和 libm，不依赖单独安装的 invLM 或数值框架。

## 测试覆盖

| CTest | 验证内容 | 证据性质 |
| --- | --- | --- |
| validation | 模型数组、深度、物性、频率、模态编号及空查询拒绝 | 输入契约 |
| halfspace | 6 个 Vp/Vs 比值 × 3 个频率、半空间高阶缺根 | 独立解析方程 |
| golden | 普通三层 5 根、低速层近邻根及缺失请求 | 上游迁移回归 |
| independent | 普通三层 5 根、低速层前 3 根 | 独立 P/SV 边界匹配 |
| scenarios | 普通、低速、高速、强对比、复杂低速层，5 个频率 | 内部方法交叉检查，非全面物理认证 |
| ordering | 乱序、重复、单条与批量、跨模型调用后确定性 | 状态与行序契约 |
| subdivision | 相同物性层细分后的根不变 | 物理不变性 |
| cutoff | 第一高阶在低频未解析、高频解析，行数保持 | 截止邻域行为，非截止频率真值 |
| numerical | 上游搜索预算触发和整数转换溢出防护 | 显式数值失败 |
| cli | 正常、缺根、无效模型、配置覆盖保护 | 端到端行为与返回码 |

半空间使用独立三次方程，令 `x=(c/Vs)²`，`k=(Vs/Vp)²`：

\[
x^3-8x^2+(24-16k)x-16(1-k)=0,\quad 0<x<1.
\]

测试用二分法求物理解，与生产求根实现无代码共享。
比值为 1.155、1.2、1.41、1.73、3、10；频率为 0.001、1、1000 Hz；
绝对容差 2e-9 km/s。未用半空间解析解替换生产后端。

分层独立参考在测试中构造四分量位移/应力 P/SV 平面波基底，
将半空间衰减解逐层传播到自由表面，求零牵引行列式的根。
预先给定根括区，不调用 invLM 的色散方程或根搜索。
普通三层五根的最大绝对误差实测 **5.00489e-13 km/s**；
普通和低速层测试统一采用 2e-8 km/s 通过阈值。
此参考是适用于所选中等光学厚度案例的非缩放传播法，
不作为高频强对比模型的生产正演或完整模态枚举器。

普通 golden 容差 2e-9 km/s；低速层近邻根的历史数值表容差 1e-8 km/s，
用于容纳编译/舍入和病态函数求值差异（本机与历史表一处约差 2.4e-9）。
它不是独立真值，也不代替独立边界匹配检查。

## 场景扫描结果

每个模型请求 5 个频率（0.01、0.5、5、20、100 Hz）× 4 阶，共 20 行。
`tests/models.hpp` 和 `tests/forward_tests.cpp` 保存完整模型定义。

| 模型 | 有效根行 | 缺失或未解析行 | 数值失败行 |
| --- | ---: | ---: | ---: |
| normal | 17 | 3 | 0 |
| low_velocity | 13 | 7 | 0 |
| high_velocity | 16 | 4 | 0 |
| strong_contrast | 13 | 7 | 0 |
| dense | 13 | 7 | 0 |

缺失行全部保留，不解释为搜索已证明模态不存在。
两个内部方程实现均有效的位置比对容差为 2e-7 km/s；
该条件式比较不证明两种方法总根数相同或所有分支已被找到。
普通模型第一高阶在 0.001–0.1 Hz 的抽样点未解析，在 0.2、0.5、1 Hz 已解析；
这不是精确截止频率估计。

## 性能基线

测量命令：

```bash
/usr/bin/time -v build/forward_benchmark normal
/usr/bin/time -v build/forward_benchmark dense_low_velocity
```

每项独立进程，40 个查询（5 频率 × 8 阶），首调用后重复 100 次。
正常模型频率为 0.1、0.3、0.5、1、2 Hz；复杂低速层为 10、30、50、80、100 Hz。
首次时间指首次 `evaluate`，不含进程启动；重复时间为每次平均墙钟时间。
RSS 为整个独立进程的峰值，不能解释为单次正演的新增内存。

| 模型 | 首次 ms | 重复平均 ms | 峰值 RSS KiB | 有效/未解析/数值失败 |
| --- | ---: | ---: | ---: | --- |
| normal | 0.378178 | 0.150924 | 4300 | 25 / 15 / 0 |
| dense_low_velocity | 0.816068 | 0.363270 | 4276 | 39 / 1 / 0 |

这些是本机单次基线，不是跨机器性能保证。困难模型与普通模型的缺根数量不同，
不能简单由耗时比推断求根效率。M1 未开展性能优化，也未将灵敏度开销混入正演计时。

## 尚未解决的数值边界

- Rayleigh 根枚举仍没有完备性证明；根聚集、近半空间端点及极端频厚尺度可能漏根。
- 上游保留绝对根去重阈值 1e-7 km/s 和搜索上限；更近的根对未被认证。
- 上游 Rayleigh 分支没有完整暴露 TOMS748 每个根的终止状态；适配层只能使用现有搜索诊断。
- 当前独立参考没有覆盖全部强对比/高频场景。内部方法一致不等于独立正确。
- 只测试了所列单位尺度、介质类别和样例；物性输入有限不代表任何极端数量级都能稳定计算。
- 截止附近的分支连续性、核函数和隐式导数可靠性尚未验收。

因此本次通过的是“明确范围的正演基线”，不能声称任意复杂层状介质均已验证。
下一项 M2 首先验收能量核、隐式导数与多步长有限差分，之后再接入观测似然。
