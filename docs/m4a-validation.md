# M4a：固定参数化的局部灵敏度与岭分辨诊断

这是 M4 的第一个独立验收项，不代表自适应分层完成。新增 C++ 核心分析和
`dispweave resolution` 命令，继续使用 invLM 已接入的正演与核函数、Eigen SVD、
现有协方差白化。Python 仅汇总与绘图；不新增依赖。

## 数学定义与解释范围

在参考模型处，固定 Vp、密度与全部界面，`q=log(Vs)`，
相速度 Jacobian `Jq[:,j]=dc/dVs_j * Vs_j`。给定观测协方差 `C=LLᵀ`，
以及用户明确提供的正参数尺度 `S=diag(scale_log_vs)`，定义

```
q = q0 + S x
A = L⁻¹ Jq S = U diag(s) Vᵀ
```

核心函数 `local_resolution(whitened_jacobian, parameter_scale, ridge, relative_rank_tolerance)`
接收已经白化的 Jacobian。它可用于其他已验证的坐标/Jacobian；CLI 本项明确限于上述固定 Vs 坐标。
尺度是研究者声明的参数度量，不是拟合后的标准差，也不自动继承 LM 的参数边界宽度。
不能比较尺度定义不一致的奇异值并据此判定复杂度。

输出分三类：

1. **奇异值与右奇异向量**：描述局部数据对给定尺度下的参数组合的敏感程度。
   数值秩为 `count(s > tolerance*s_max)`，默认相对阈值 `1e-12`；
   它只区分数值零空间，不能解释为可辨识层数。
2. **岭滤波因子与有效维度**：对明确的线性化问题
   `min_x (||Ax-b||² + alpha²||x||²)/2`，`alpha=ridge>0`，
   `f_i=s_i²/(s_i²+alpha²)`，`d_eff=sum(f_i)`。
   它是该岭估计器的数据拟合有效自由度，依赖噪声、参数尺度和 alpha；不是无先验的物理自由度。
3. **模型分辨矩阵**：`R_x=V diag(f_i) Vᵀ`。
   在该局部线性模型中，真值扰动 x 到噪声平均岭估计的映射为 `E[x_hat]=R_x x`。
   原 q 坐标映射为 `S R_x S⁻¹`，文件中保存的是 x 坐标矩阵。
   层级图展示 `diag(R_x)`，需要同时查看非对角泄漏和右奇异向量。
   它不是后验协方差、可信区间或以 km 表示的垂向分辨长度。

本项**没有把岭正则化加入 LM**，也没有自动选取 alpha；它是显式参数化的诊断实验。
改变 alpha 本身就能改变 d_eff，因此不能仅凭 d_eff 下降声称数据已自动撤回模型细节。
同样不能用 `diag(R)` 的阈值直接决定新界面。

计算保留完整 V 和所有参数方向；观测少于参数时，将未观测奇异值补零，保留零空间。
重根对应的右奇异向量基底和单列符号可能随平台变化，不能逐列赋予唯一物理含义。
零矩阵返回零秩、零有效维度和零分辨矩阵。
滤波因子采用比例运算避免直接平方极大奇异值；非有限输入、错误维数、零/负尺度或 ridge 明确拒绝。

## 配置、命令及输出

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
ctest --test-dir build --output-on-failure
build/dispweave resolution --config examples/resolution/reference.toml --output results/local-resolution
python scripts/run_resolution_example.py --output results/m4a
```

示例脚本需要 NumPy、Matplotlib，核心命令不需要 Python。输出目录必须新建或为空。
模型和配对查询使用原有 `[model]`、`[queries]`；新增：

```toml
[resolution]
scale_log_vs = [0.1, 0.1, 0.1]
sigma_km_s = 0.005
ridge = 1.0
relative_rank_tolerance = 1e-12
sensitivity = "energy"
```

`sigma_km_s` 定义同方差独立误差；也可以用 `covariance = [[...], ...]` 指定完整协方差，
但不能同时提供两者。矩阵按查询行顺序，单位 `(km/s)^2`，必须对称正定。
允许 `sensitivity="implicit"`；任意根或核不可用就终止分析，不能丢弃对应观测行。
本命令分析参考模型的实验设计，无需观测相速度；残差不影响本项的局部 Jacobian 诊断。

输出保存配置副本、逐行正演/核诊断、实际协方差、缩放白化 Jacobian、奇异值和滤波因子、
完整右奇异向量与分辨矩阵、层顶/层底/参数尺度/矩阵对角元，以及版本/方法/阈值元数据。
半空间层底写为 `inf`，没有人为截取半空间的探测深度。

## 验收与实际结果

Linux/WSL、GCC 13.3、CMake 3.28.3，Release **26/26** 通过（首次完整测试 0.39 s）。
Debug + UBSan（`-fsanitize=undefined -fno-sanitize-recover=all`）也为 **26/26**，
完整测试 4.58 s，未报告未定义行为。
在 M3 的 22 项基础上增加 3 项 C++ 测试和 1 项 CLI 工作流测试：

- 解析对角/欠定矩阵、零矩阵、零空间；一般矩阵与独立线性系统求解结果对照。
- 一致参数单位变换、白化空间正交变换、相关协方差下的观测行置换不变性。
- 增加独立观测、提高噪声或岭强度对有效维度的影响；验证提高噪声与提高 ridge 的数学等价关系。
- 非法尺度/维数/非有限输入与极大奇异值；CLI 的缺根、完整协方差、非正定矩阵与覆盖保护。

12 组实验在同一三层参考模型处计算（层顶 `[0,2,4]` km，Vs `[1,2,3]` km/s），
比较 7 个基阶频点与追加 7 个第一高阶频点；0.2–1 Hz，scale_log_vs 全为 0.1。

## 限制与后续独立里程碑

只完成固定参数化诊断基线，M4 整体保持未完成：

- 在四类模型、不同频段/观测覆盖下系统比较度量、模态与噪声，不能从当前单模型推广。
- 近截止与分支变换处不能仅由“核有效”推断局部线性近似在有限扰动范围内成立；
  本项不新增跨截止可微保证，沿用 M2 的限制。
- 不计算可信区间或贝叶斯有效维度，不涵盖 Vp/密度/界面不确定性，也未处理触界约束下的切锥。
- 后续计划已调整：M4b 的候选评分路线撤回，M4c 自适应分层暂缓。
  优先完善固定层数 LM，再推进固定层数 HMC；现有诊断不用于自动决定层数。
  若在固定层数下反演层厚，仍须独立验证厚度/界面导数。
