# M4b：候选参数化与复杂度准则对照

新增 C++ 候选评估接口及观测反演的独立验证数据入口，保留固定层界面的 Vs 参数化。
Python 负责生成实验矩阵、调用 CLI、汇总和绘图；正演、核、LM、似然、AIC/BIC 和局部分辨计算均在 C++。
没有添加第三方依赖，也没有实现自动增层/合并。

## 两类准则与适用条件

1. **信息准则**：`AIC=-2 log L + 2k`，`BIC=-2 log L + k log(n)`。
   `log L` 使用完整归一化 Gaussian likelihood，`n` 是本次训练观测行数，`k` 是拟合 Vs 参数数。
   当前协方差已知、Vp/密度/界面固定，故没有额外拟合的噪声或界面参数。
   不以数值秩或岭有效维度替换 k。AIC/BIC 的形式和同数据、最大似然比较要求见
   [R stats 官方说明](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/AIC.html)。
2. **独立验证预测分数**：`validation_nll=-log p(d_validation | m_hat_training)`。
   使用独立误差的新观测，在训练选出的最佳收敛初值上计算，保留其协方差归一化。
   它是固定估计模型的预测分数，不是后验预测积分或边际证据。
   AIC 与 BIC 属于同一惩罚准则家族；独立验证似然才是本项第二类方法。

所有排名只在**同一场景的候选集合**内进行，不能跨噪声、模态或覆盖直接比较原始分数。
每个候选首先仅依据训练代价选出最佳收敛初值，验证数据不能决定初值或 LM 步骤。
真值误差仅在事后报告，不进入任何候选选择。

`assess_candidate` 的局部检查：

- 未收敛或末次评估无效，不提供可排名分数。
- 解距离任一边界不超过 log 参数边界宽度的 `1e-8`，不参与 AIC/BIC。
- 缩放白化 Jacobian 数值秩不足，或 `n<=k`，不参与 AIC/BIC。
- 通过时标记 `local_screen_passed`，不称为全局 MLE 或渐近理论已获认证。
- 已收敛的触界解可以计算验证预测分数，因为该分数不依赖内点渐近展开。

这些只是必要的局部筛查：小样本、非线性、错设模型、弱约束或局部极值都可能使
AIC/BIC 的理论解释失效。尤其不能将本项的 BIC 差值直接转换成层数后验概率。
对一般相关协方差，观测行数也不自动满足 BIC 的独立样本渐近假设；本项实验使用独立误差。
`[assessment]` 的尺度与 ridge 只用于 M4a 局部诊断，没有给 LM 加入正则化。

## 接口与复现

C++：`information_criteria(log_likelihood,n,k)` 和
`assess_candidate(fit,lower,upper,scale,ridge)`，定义在 `selection.hpp`。
沿用 `invert` 子命令，在配置增加：

```toml
[assessment]
scale_log_vs = [0.1, 0.1, 0.1]
ridge = 1.0
```

```bash
build/dispweave invert --config candidate.toml --data train.txt \
  --validation-data validation.txt --output results/candidate
```

训练仍支持 `--covariance`；验证块支持 `--validation-covariance`。
**训练与验证两块误差必须独立**，各块内部可有非对角协方差；当前不支持两块间的交叉协方差。
本项不实现联合相关误差的条件预测似然。用户需要按观测来源保证独立性，不能把同一数据复制一份当验证。
验证缺根写出 `validation_status=forward_failure` 和不可排名分数，保留原行；不改变已完成的训练拟合。
进程返回码仍表示训练是否至少有一个初值收敛，验证状态需另看 `assessment.txt`。

新增输出：

- `assessment.txt`：训练最佳初值、n/k、尺度/ridge、局部筛查原因、AIC/BIC、局部信息量及验证分数。
- `assessment_spectrum.txt`、`assessment_resolution.txt`：拟合模型处的谱和岭分辨矩阵。
- `validation/observations.txt`、`validation/covariance.txt`、`validation_prediction.txt`：验证输入与逐行预测。

没有 `[assessment]` 时保持原 M3 工作流。验证入口要求该配置；所有初值失败时仍保存 `fitted=0`，不制造最佳候选。

完整实验：

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
ctest --test-dir build --output-on-failure
python scripts/run_selection_study.py --output results/m4b
python scripts/plot_selection_study.py results/m4b
```

`--smoke` 只运行第一个模型、一个种子、完整频段、两个模态及两种噪声，合计 6 个候选拟合。
脚本需要现有 NumPy/Matplotlib。所有输出目录必须新建或为空。
配置为 `examples/selection/study.json`，输入快照和随机误差向量均保存。
NumPy PCG64 的 `SeedSequence([seed,model_index])` 生成训练和验证的独立标准正态向量；
跨模态、频段掩码与噪声水平重用同一主向量，实现配对实验。保存的数据是重放依据。

## 实验设计

四类合成模型都在层顶 `[0,.5,1,2,3,4]` km 上定义：

| 模型 | Vs (km/s) |
|---|---|
| 平滑梯度的分层近似 | 1, 1.2, 1.45, 1.8, 2.3, 3 |
| 清晰界面 | 1, 1, 1, 2.2, 2.2, 3 |
| 低速夹层 | 1.1, 1.8, 1.1, 1.8, 2.4, 3 |
| 浅部细节加深部梯度 | 1, 1.8, 1.2, 1.65, 2.2, 3 |

这些是固定的离散合成模型，第一类并非连续介质极限的验证。
Vp=6 km/s、密度=2.5 g/cm³ 在全部真值和候选中保持一致，隔离 Vs 参数化的影响。
候选为 3、5、6 参数的固定层顶网格：`[0,2,4]`、`[0,1,2,3,4]`、`[0,.5,1,2,3,4]`。
最细候选包含真值网格，是有利的已知网格实验，不代表未知界面问题已经解决。
边界统一为 Vs 0.6–3.8，三个初值为固定梯度及其 0.95/1.05 倍，不从真值初始化。
LM 上限 200、投影梯度阈值 `1e-4`，所有场景相同。

- 模态：仅基阶、基阶加第一高阶、再加第二高阶。
- 完整频段：基阶 0.12–1.7 Hz，第一高阶 0.3–1.7 Hz，第二高阶 0.6–1.7 Hz，采样不等长。
- 覆盖：完整；仅保留 f≥0.35 Hz；按主观测行序移除每三行的第二行。
- 噪声标准差：0.005、0.03 km/s；种子：2026、2027。
- 验证是同查询频点的独立噪声复测，不是频带外预测或留频点插值验证。

共 `4 × 3 × 3 × 2 × 2 = 144` 个场景，每个 3 候选、3 初值，432 次候选拟合、1296 条初值轨迹。
剖面真值误差是 0–6 km 上分段常数 Vs 的精确积分 RMSE；6 km 只是统一评价范围，不是探测深度。
`candidates.csv` 保留训练代价、真值 RMSE、谱有效维度、失败计数和全部候选状态。
`selections.csv` 同时写出获胜候选与 eligible 数量；数量不足 3 的比较一律视为不完整。
绘图和噪声效应汇总仅使用低/高噪声时全部候选都合格的成对场景。

## 实际验证结果

Linux/WSL、GCC 13.3、CMake 3.28.3：Release **29/29**（0.45 s）、Debug + UBSan **29/29**（5.24 s）。
新增：信息准则解析检查、边界/秩/失败筛查、独立 Gaussian 预测归一化；
改变验证数据不改变训练轨迹/最佳初值/AIC 的集成测试；验证缺根与训练全部失败路径。

四个新模型分别抽查 `(f,mode)=(.12,0),(.3,1),(.6,2)`，共 12 个根：
独立 P/SV 边界匹配根与 invLM 最大差异 **5.03e-13 km/s**。
每层 Vs 核与相对步长 `1e-4`、`1e-5` 的中心差分比较，最大 `|FD-kernel|/(1+|kernel|)` 为 **4.35e-8**。
独立求根在给定根附近构造区间；这验证了该根，而不是所有阶根枚举的完备性。
未将抽查推广为所有试算、所有频点和复杂模型的全面认证。

全矩阵运行 11.49 s（含子进程、输入/结果写出，不含后续绘图），C++ 命令记录时间合计 9.71 s。
单独复测梯度模型、两个模态、sigma=.005、六参数候选：三初值与评估命令内计时 30.91 ms，
`/usr/bin/time -v` 墙钟 0.04 s、最大 RSS 6100 KiB。它是一次本机测量，不是跨平台性能保证。
449 个第三方文件哈希校验全部通过。结果与图保存在 `results/m4b/`，生成文件不纳入提交。
本次结果：

| 模型 | 候选数 | 有收敛初值 | 通过局部 IC 检查 | 所有已收敛候选剖面 RMSE 中位数 (km/s) |
|---|---:|---:|---:|---:|
| 梯度 | 108 | 96 | 87 | 0.1873 |
| 界面 | 108 | 101 | 90 | 0.0492 |
| 低速层 | 108 | 81 | 74 | 0.1984 |
| 浅部细节 | 108 | 80 | 61 | 0.2411 |

RMSE 中位数包含所有已收敛候选，不是选中模型的精度或覆盖率。
合计 358/432 有收敛初值；74 个全部未收敛；另有 46 个触界，故 312 个可计算探索性 AIC/BIC。
826/1296 条初值轨迹收敛。共有 3619 次正演失败评估（包括初值和试算、每次按整个观测向量计一次），
核失败评估为 0；没有删掉对应观测。
已收敛候选训练代价范围 0.073–4743.94，说明收敛本身不表示模型能够充分解释数据。

144 个场景中，68 个的 IC 候选集合完整，84 个的独立验证候选集合完整。
在共同完整的 68 组里，BIC 与验证似然的选择有 16 组不同。

- 噪声升高：BIC 有 23 对完整配对，其中 4 对选择更少参数、19 对不变；
  验证似然有 30 对完整配对，全部不变。两类准则的配对集合不同，不作统计优劣判定。
- 仅基阶与三个模态：BIC 有 12 对共同完整场景，1 对选择更多参数、2 对更少、9 对不变。
  不能声称增加高阶必然要求增层。
- 浅部细节的 BIC 噪声对照没有共同完整配对；图中明确标记，不以缺失结果制造趋势。

本项是两种子的方法对照基线，不能给出普遍复杂度变化、统计显著性或后验层数概率。
验证数据一旦用于候选选择，就不能再作为无偏的最终泛化误差测试；后续性能评估需独立第三块数据或嵌套验证。

## 下一项与未解决问题

M4b 的固定候选比较已完成；M4c 自动增/并/减参数尚未实现。
目前主要限制是弱约束、触界、局部极值及未收敛候选造成的不完整比较。
下一项必须首先定义候选求解失败时的“比较未完成”状态与重试策略，不能默认失败候选应被淘汰。
随后在固定候选界面集合中验证增加/合并的可逆性、候选一致性及复杂度规则；
连续移动界面仍需独立的界面/厚度导数验收。
保留信息准则和独立验证两条路线，不能将本次少数简化案例写成已证实的自动复杂度控制。
