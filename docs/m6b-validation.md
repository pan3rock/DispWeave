# M6b：预热期分窗口质量矩阵适应

版本 0.7.2。本项在已有静态 HMC 上增加 `none`、`diagonal`、`dense` 三种 metric_adaptation。
默认 `none` 保持原 M5 固定质量矩阵路径。模型维度、物理正演、先验和似然不改变。
不自动增减层数；NUTS 和 M6 的完整科学基准仍在后续 M6c。

## 定义与适应日程

质量矩阵 M 始终指无约束 z 坐标中的**动量协方差**，因此学习位置协方差 C 后设置 M=C⁻¹。
使用 Welford 累加器，每个窗口只记录该窗口的采样状态（包括拒绝后重复状态），窗口结束清空。
对角模式仅保留各参数方差；稠密模式保留交叉协方差。

n 个窗口样本的正则化协方差：

`C_regularized = n/(n+5) * C_sample + 5/(n+5) * 1e-3 * I`。

固定 z 坐标中的 ridge 保证低样本数/重复状态下正定；它只影响采样效率，
没有修改目标密度或模型先验。通过 LLT 求解得到质量矩阵；积分中的 M⁻¹p 仍用三角求解。
数值非有限或分解失败显式报错，不静默替换单位质量。

预热 >=150 时：初始快速阶段 75 次，终止快速阶段 50 次，中间慢窗口从 25 次起翻倍；
不足以容纳下一个完整倍增窗口时，将剩余慢阶段合入最后一个窗口。
例如 1000 次预热的慢窗口为 `[75,100), [100,150), [150,250), [250,450), [450,950)`。
较短预热（20–149）使用 15% 初始缓冲、10% 终止缓冲和一个中间窗口；
低于 20 次拒绝开启质量适应。这只是支持短测试，不意味着 20 次足够用于研究后验。

每次更新质量矩阵后重新初始化 dual averaging；最后的快速阶段只调整步长。
正式采样不再更新任何适应状态。质量适应要求同时启用步长适应，防止沿用与新尺度不兼容的步长。
本实现不声称完全复刻 Stan 的所有预热行为；例如不额外搜索初始合理步长，
而由已实现的 dual averaging 在给定预热预算内调节。复杂局部曲率不能靠全局质量矩阵消除。

日程和 Welford 思路参考 [Stan HMC 说明](https://mc-stan.org/docs/reference-manual/mcmc.html)。
代码在 `src/sampler_adaptation.hpp`，dual averaging 从原 HMC 路径提取，可供后续 NUTS 共享。
每条链输出最终 `chain_*_mass.txt` 以及每次窗口更新的 iteration、样本数和质量矩阵。
原 `mass.txt` 仍表示用户指定的初始质量；不得将二者混淆。

## 数值验收

- 已知小数据的 Welford 协方差、正则化公式、质量矩阵方向与手算矩阵相符。
- 检查快速缓冲、窗口连续性、终止快速阶段前冻结。
- 改变正式样本预算不改变最终质量矩阵或已有样本前缀；不足预热被拒绝。
- 两维高斯位置方差为 .01 和 100（比值 10000）；另将其旋转形成强相关目标。
  对角/稠密适应分别使用 17、2026、99173 三个种子，2000 预热、12000 正式样本。
  白化后的均值/二阶矩采用 M5 同样的 `max(.04,6*batch_MCSE)` 容差，MCSE <.10；
  六组全部通过，正式采样无发散。没有因适应结果不同而放宽阈值。
- CLI 回归检查配置解析、对角质量正值、非对角元素为零以及窗口记录。
- Release 完整回归 38/38（2.09 s）；UBSan 力学、分布、失败、适应定向回归 4/4（13.46 s）。
  后补 CLI 适应检查另做定向回归，1/1 通过（1.74 s）。

## 频散对照

```bash
build/dispweave hmc --config examples/hmc-adaptive/synthetic.toml \
  --data results/m5/data/observations.txt --covariance results/m5/data/covariance.txt \
  --output results/m6/adaptive-hmc
python scripts/posterior_diagnostics.py results/m6/adaptive-hmc --output results/m6/adaptive-diagnostics.json
python scripts/compare_hmc.py results/m6/adaptive-hmc results/m5/reference_*.txt
```

与 M5 完全相同的观测、协方差、先验、初值、三个 chain id、随机种子、1000 预热、
每链 4000 样本、L=12 和目标接受率 .95。唯一算法配置变化为对角质量适应。

| 参数 | 原 R-hat | 适应后 R-hat | 原 bulk ESS | 适应后 bulk ESS | 适应后 tail ESS |
|---|---:|---:|---:|---:|---:|
| Vs 0 | 1.00146 | 0.99998 | 6048.3 | 12684.8 | 8426.1 |
| Vs 1 | 1.00230 | 1.00007 | 1418.8 | 25883.7 | 6659.8 |
| Vs 2 | 1.02464 | 1.00049 | 93.8 | 4788.7 | 6619.5 |

ESS 超过原样本数可以来自反相关，不裁剪为样本数；它不是实际新增的独立样本数。
尾部 ESS 仍须检查，单个参数较高 bulk ESS 也不代表所有后验函数都有效。

三条链接受数为 3853、3868、3854 / 4000，正式发散与无效评估均为 0。
链 0 最终 M 对角约 `(654.593,14.971,0.34090)`，体现不同参数尺度。
两种算法的正式梯度评估都为 144000；原预热评估 36000、适应后 35863（部分试算提前失败）。
这些失败均保留在预热 trace 中；没有把正式失败隐藏到平均数里。
本机 C++ 计时 14.64 s，单次计时含 I/O，不据此单独声称通用加速比。
主要效率证据是相同正式梯度预算下的 ESS 改善。

适应后的 Vs 均值约 `(1.002487,1.971513,3.085455)` km/s，均值 MCSE
约 `(0.0000589,0.000414,0.00421)` km/s。与 M5 的独立 MCMCLib 数据比较，
三组均值和六个中心二阶矩均通过原先定义的容差，未因为适应而改变目标后验。

这仍是固定步数、局部梯度方法。预热质量估计依赖预热探索，不能保证发现孤立模态，
也不能自动修复漏斗局部曲率；这些局限将与 NUTS 一起在 M6c 分别实验。
