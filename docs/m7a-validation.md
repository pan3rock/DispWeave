# M7a：跨维状态、先验与可逆提议

M7a 完成后只提供状态与确定性提议接口，还不是 RJMCMC 采样器。
M7b 将增加随机动作调度、连续更新和解析跨维采样验证；M7c 才接频散。
数学定义、固定动作概率及物理适配边界见 [M7 设计](m7-design.md)。

## 实现

- `RJState` 使用有序内部界面和物理 Vs；末层是半空间，没有单调速度限制。
- `RJPrior` 校验层数范围（工程上限 10000）、正最小间距、有限正深度支持、
  正 Vs 范围与层数权重。零权重对应零先验质量。
- 位置先验为最小间距约束下的归一化有序点分布；权重归一化先缩放，避免大权重求和溢出。
- `rj_birth`/`rj_death` 返回状态、界面索引、正反 log 提议密度和 log Jacobian。
  动作概率显式计入；确定性接口使提议可独立检查，不隐藏目标或 RNG。
- 插入位置按整个可行区间并集均匀抽取，而不是均匀选层。
  没有插入空间、达到层数边界时返回 `unavailable`，保留源状态。
- 越出支持、零目标层数权重或零测度的逆插入返回 `outside_support`。
  源状态错误、非法索引或动作概率错误则抛出输入异常。
  浮点端点饱和不裁剪为人为有效点。

birth/death 在精确边界上的处理：当删除后原界面只位于一个零长度插入集合中，
即使其他层仍可插入，也拒绝该 death。该情况不能套用其他区间的密度作为逆概率。
普通连续更新之后可以离开这种边界，后续采样器将显式记录提议失败。

## 验证

`tests/rj_tests.cpp` / CTest `rj_contracts` 包含：

1. Z=4、h=.5、Vs∈[1,3]、p(K)∝(1,2,3) 时，K=1/2/3 的状态密度
   分别为 1/12、1/36、.02；独立积分有序界面的三角区域恢复 K=3 概率 .5。
2. 权重乘 1e300 后密度不变；零权重、非有限值、错维、界面交叉、
   最小间距和零体积支持分别检查；低速层被允许。
3. 多个可行辅助量下 birth→death 精确恢复源状态，正反 log Hastings 比相消。
4. 直接核对 1→2 和 2→3 的完整提议密度，验证动作概率、区间总长度、
   Vs 范围和可删除界面数均被计入。
5. 对两种插入位置作五维有限差分 Jacobian 检查，绝对行列式为 1。
6. 加上非平凡 Vs/界面目标因子后，正反 `pi*q*acceptance` 的 log 流量相等。
   此项配合独立密度与 Jacobian 检查，而非仅检查一个自相抵消的公式。
7. 可行区间长度比 1:4 时，10000 个等距均匀辅助坐标恰有 2000 个落入短区间；
   排除零长度区间，验证空插入集合、上下层数边界、非法输入和零测度逆提议。

Release 完整回归 41/41 通过（8.85 s）。最后新增的输入/精确边界测试另作定向回归。
最后新增检查的 Release 定向回归通过；UBSan 定向回归 1/1 通过（.06 s）。
未重复执行没有改动的 M6 长时间 UBSan 工作流。

这些测试验证 M7a 契约，不证明跨维采样混合，也不提供层数后验科学结论。
M7 的解析采样与物理反演验收仍须分别完成。
