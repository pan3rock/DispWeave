## 固定维度联合工作流

`joint-data` 从明确的生成模型创建观测与基准协方差，保存生成信号、随机种子和配置。
`joint` 只读取显式 `values`，即使输入含有 `[synthetic]` 也不会重新生成或替换观测。
两条命令均要求输出目录新建或为空。输入、每块观测、协方差、版本及处理参数均保留。

观测名称只允许安全文件名标识符；必须声明 `independent_blocks=true`、物理量与单位。
每块只能提供 `sigma` 或完整 `covariance` 之一；块间条件独立并不意味着块内白噪声。
接收函数由 `sample_indices` 选择完整处理网格上的样点，窗口、滤波、水位、源和时移
沿用 M8b 契约。标签为 `rayleigh_modal_ellipticity` 的数据必须确是已提取模态椭圆率。

模型参数为固定层顶、固定密度下的 Vs；Vp 可固定或按指定 Vp/Vs 随动。
本次实验固定 Vp。模型先验明确声明 physical_vs 或 log_vs 测度；噪声先验由各块声明。
保存状态顺序为 `[log(Vs), 按块声明顺序的待估 log(s)]`，固定尺度不占状态维度。
输出物理 Vs、完整状态、log posterior、提议轨迹和最终协方差，保留所有拒绝后的重复状态。

可选 LM 复用 bounded_lm：噪声固定在各先验的初值，频散使用已验证核，新增块使用
M8c 的两级步长有限差分。输出终止分类、投影梯度与完整试算轨迹；LM 结果不代替链的初值。
后验链使用配置里逐链提供的分散初值，模型先验只计一次。

## 为什么采用无梯度 Metropolis

椭圆率和 RF 尚无经过验证的模型梯度，M8c 的联合 HMC 入口仍明确拒绝这些块。
本项增加通用的值目标 Metropolis，实现与物理、参数化和联合目标解耦，没有复制物理代码，
也没有把有限差分包装成已验证的 HMC 梯度。原 HMC/NUTS/RJMCMC 接口不变。

在状态 x 中提出 `x'=x+a*chol(C)*z`，`z~N(0,I)`；冻结时提议对称，接受率为
`min(1, exp(log_pi(x')-log_pi(x)))`。不裁切或反射越界点，支持域外是正常拒绝。
数值/正演失败保留独立状态；不能将失败模型解释为先验排除。目标函数非有限值和错误的
支持域返回值单独标为数值失败。若生产期出现数值失败、零接受链或预测失败，CLI 返回 5。
初值、输入或 I/O 错误返回 1；返回 0 仍须检查多链和物理诊断。

仅在 warmup 内使用已有的 DualAveraging 调整 a，分窗口估计正则化稠密位置协方差 C。
复用的协方差收缩为 `n/(n+5)*sample_cov + 5/(n+5)*1e-3*I`。
HMC 原有的质量矩阵依然取相同协方差的逆；Metropolis 使用协方差本身。
warmup 后 a、C 全部冻结，所有正式样本均保留。默认目标接受率 .234 是可配置的调参目标，
不代表任意维度或分布的最优值。每条链的 seed/chain_id 使用独立 seed_seq；后验预测另用随机流。

`tests/metropolis_tests.cpp` 检验三个种子的相关 Gaussian 均值/协方差、均匀有界目标的
边界偏差与重复状态、指数分布、种子重放/链独立、非正定矩阵和失败状态。
独立物理后验验证采用下述网格积分，不以解析 toy 目标代替联合反演验收。

## 后验预测和诊断

每链等间隔选取声明数量的正式样本；每块输出潜在预测 g、带相关噪声的复制数据
`y_rep=g+s*L0*z`、实际与复制数据的白化 chi-squared、尺度 s。预测状态逐条保存；
失败行保留 NaN，不被删去。复制数据和潜在信号的区间在图中分别显示。

`joint_results.py` 核查链数、样本数、预测索引、状态和生产期步长冻结，再复用 M6 的
rank/folded split R-hat、bulk/tail ESS、mean MCSE。参数包括 Vs 和所有待估尺度；
warmup/正式期分别统计状态和接受数。缺链、缺预测、失败预测或非有限值阻止生成总结。
`no_flag` 不证明遍历了所有后验模态。输出每块 RMS、预测区间、尺度区间、PPC chi-squared
及 `P(chi_rep²>=chi_obs² | y)`；PPC p 值使用同一数据拟合后的预测分布，不是经典均匀 p 值。
若预测抽样数量有限，极小尾概率只能报告为本次复制样本未观察到超越，不能解释为概率严格为零。

Vs 区间条件于指定界面、Vp、密度、误差模型和先验，不包含层数、界面或物理模型不确定性。
较窄区间不等于深度分辨率提高；固定两个 Vs 的合成实验不支持任意精细结构可分辨的结论。

## 独立后验积分

验证程序 `joint_grid` 遍历整个二维物理 Vs 支持域，调用已经验证的三个物理模块，保存
各块单位尺度 chi-squared，任何失败节点均显式保留且返回非零值。它不使用联合 log posterior
或 Metropolis。Python 独立重建物理 Vs 先验和每块的尺度积分：

```
L_b(Vs) ∝ integral exp(-chi_b²*exp(-2 eta)/2 - n_b*eta)
                      * Normal(eta; mu_b, sd_b) d eta
```

协方差等与 Vs 无关的归一化常数在归一化参考后验时抵消；`-n_b*eta` 必须保留。
log_vs 均匀模型先验在物理 Vs 网格中的密度含 `1/prod(Vs)`，physical_vs 均匀则是常数。
尺度积分用 Gauss-Legendre，模型积分用二维梯形规则；比较尺度节点加倍与模型网格减半的
结果变化，并将 Vs/噪声尺度的采样均值误差与 5 MCSE 加两倍积分变化对照。
尺度使用 384 个积分节点，与 192 节点比较；积分范围为先验均值 ±10 个标准差，
另外扩展到 ±12 个标准差（460 节点）检查截断影响。该容限是预先声明的数值验收界限，
不代表单次统计检验能证明全部采样正确。

均值容限与采样检查必须同时通过：沿用 M6 的 R-hat ≤1.01、bulk/tail ESS 均不低于
每链 100 个的总量要求，检查 Vs 及所有噪声尺度，且不得有数值提议失败。
未混合的链会放大 MCSE，可能使错误均值仍落在上述容限内；因此不能只依赖均值对照。
脚本保存所有案例和失败原因后返回非零，不删除失败组，也不让一个失败组阻止其他组的核对。

```bash
build/joint_grid results/m8/joint-validation/consistent-data/observations.toml results/m8/joint-validation/consistent-grid.txt 201 161
build/joint_grid results/m8/joint-validation/conflict-data/observations.toml results/m8/joint-validation/conflict-grid.txt 201 161
python scripts/check_joint_grid.py results/m8/joint-validation \
  --consistent-grid results/m8/joint-validation/consistent-grid.txt \
  --conflict-grid results/m8/joint-validation/conflict-grid.txt \
  --output results/m8/joint-validation/grid-validation.json
```

参考积分本身另外通过 lognormal 矩母函数、物理/对数均匀先验的解析均值以及固定尺度
Gaussian 均值/标准差检验。
