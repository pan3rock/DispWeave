# 慢链最后更新前后矩阵的隔离对照

接续 [末段步长重启试验](nuts-terminal-step.md)。此前搜索和延长适应没有消除慢链的高正式成本，
这次固定同一个检查点，比较最后更新前、后的质量矩阵，并分别适应步长。

## 固定方案

- 起点同为 `nuts-original-095` 链 0 零基转移 949 结束状态，不替换成更容易的后验位置。
- before 矩阵由状态 250–449（200 个）重建，after 由 450–949（500 个）重建。
  使用原默认协方差正则化和动量协方差约定；与上一轮局部曲率诊断的矩阵分别核对一致。
- 两组的配置除动量协方差外完全相同：slice、目标 0.95、合理步长搜索、标准双平均、
  100 次步长适应＋300 个正式状态；固定矩阵，不启用温和重启或局部刚性保护。
- 初始步长相同，取原更新后第一步使用的 0.150282685 左右，不给任一组手选步长。
- 各 4 个独立随机流，seed 20261027、chain ID 0–3，共 8 次；交错提交，四个数值进程并发。
- 每次 300 秒上限，名义采样预算 600 秒，另有调度与审计开销；不重试、不临时扩展。
  任何一组有不完整重复就不汇总该组 ESS，不取共同短前缀代替预定完整输出。
- 先比较发散和数值失败，再比较 49 个量中最低 bulk/tail ESS 除以总评估（包括搜索和预热）。
  同时报告 R-hat、半段诊断和正式每状态成本；这些是相同检查点的条件性短链指标，
  不代表分散初值验收，更不替换原正式结果。

```sh
python scripts/benchmark_nuts_terminal_step.py --exe build/dispweave \
  --source results/nuts-original-095 --output results/nuts-metric-pair-new --compare-metrics
MPLCONFIGDIR=/tmp/dw-matplotlib python scripts/plot_nuts_terminal_step.py results/nuts-metric-pair-new
```

## 实际结果

八次均完成，未超时，每组 4×300 个正式状态。旧矩阵单次约 118–130 秒，新矩阵约 208–234 秒。

| 指标 | 更新前 before | 更新后 after |
|---|---:|---:|
| 冻结步长范围 | 0.1280–0.1428 | 0.0555–0.0663 |
| 正式每状态平均评估数 | 31.21 | 58.67 |
| 总评估（含搜索与预热） | 53719 | 95899 |
| 最低 bulk ESS（49 个量） | 42.23 | 524.79 |
| 最低 tail ESS | 316.22 | 548.40 |
| 最大 R-hat | 1.06377 | 1.01244 |
| 最低 bulk ESS / 千次总评估 | 0.786 | 5.472 |
| 最低 tail ESS / 千次总评估 | 5.887 | 5.719 |

**新矩阵每状态更贵，但最低 bulk ESS/总成本约为旧矩阵的 6.96 倍。** 尾部效率比约 0.97，
没有同样提高，不能声称所有指标统一提速。逐量 bulk ESS/成本比值中位数约 2.00，
49 个量中 42 个改善；最低量的提升幅度不代表所有参数都提升 7 倍。

旧矩阵的最低 bulk ESS 来自 Vs[15]：42.2；新矩阵同一参数为 940.7。
新矩阵最低量变成 reference_quadratic（524.8），45 个 Vs 的最低 bulk ESS 为 680.0。
两半各 150 状态的最低 bulk ESS，旧矩阵为 30.0 / 38.4，新矩阵为 288.3 / 263.8，
改善方向在两半均出现，但短链的具体倍数仍有不确定性。

正式期两组均无发散、数值失败、支持域拒绝或树深截断。预热旧矩阵共 3 次发散、无数值失败；
新矩阵 2 次发散且有 2 次数值失败，不能省略重启时的不稳定性。JSON 中非有限最大能量误差
序列化为 null，不代表误差为零。

## 对此前判断的修正

“链 0 慢”此前主要指状态生成速度，不能直接当成有效采样效率差。
最后矩阵更新带来的小步长与更多积分步，在本轮换来了更好的主体混合。
这与先前局部 GN 诊断中“最高频率升高，同时条件数改善”的结果相符，但局部诊断本身
并不能替代本次真实轨迹对照。

因此不应为了恢复大步长而拒绝这次矩阵更新，也不宜继续以每状态调用数最少为优化目标。
后续若优化，需同时衡量最低 bulk/tail ESS/总成本和诊断，保留正式期正确性约束。
本轮不新增矩阵拒绝规则、不改变默认采样器。

两组最大 R-hat 均未达到 1.01；相同检查点的短链对照不构成完整后验验收。
约 7 倍只适用于本轮最低 bulk 指标，不是从原始初值开始的全流程加速结论。
