# 保留首次启动，仅温和重启质量适应

[原始初值在线检查](nuts-online-warmup-audit.md) 显示全程温和策略拖慢初次启动。
本轮新增独立选项 `conservative_metric_restart`，只修改接受质量更新之后的重启。
`conservative_warmup` 保留原语义，旧实验仍可重现；两个选项默认均关闭。

## 行为和验证边界

```toml
kernel = "multinomial"
find_initial_step_size = true
metric_adaptation = "dense"
metric_shrinkage = 25.0
conservative_warmup = false
conservative_metric_restart = true
metric_max_stiffness_ratio = 4.0  # 独立选项；0 表示不检查
```

首次启动继续使用原搜索和双平均中心，保持原 RNG 消耗。仅在接受质量更新后，取上一段
平滑步长，进行四组固定随机动量的只减半搜索，之后双平均以该步长为中心。
若没有开启步长搜索，则仍使用平滑步长重启双平均。拒绝矩阵更新时不重启，不额外消耗随机数。
新选项要求启用质量适应；若同时开启 `conservative_warmup`，首次启动也继续采用温和策略。
正式采样的树内核、目标密度、先验和冻结行为不变。

测试覆盖两种树内核、有/无初始步长搜索的首次 100 次轨迹逐位一致；首次候选质量矩阵一致；
拒绝所有矩阵时与不适应矩阵的采样路径一致；新策略单独及配合矩阵检查在三个种子的相关高斯
目标上验证分布矩、正式期冻结和重放。真实三层 CLI 同时验证新选项、先验中心及额外调用计数。

## 运行前固定的在线试验协议

两个原始初值（参考 Vs −0.2 / +0.2），seed 20261023，45 维、125 个观测；
原始模型、物理 Vs 先验和支持域不变。Gauss–Newton 初始质量矩阵，multinomial，dense，
k=25，目标接受率 0.99，最大树深 10。计划 300 预热＋100 正式状态，单链最多 120 秒。
两种方案各两个初值：仅温和矩阵重启，以及温和矩阵重启＋在线刚性比检查（阈值 4）。
两个数值工作进程，固定四次任务，不重试、不追加预算，不扫描参数。

```sh
python scripts/benchmark_nuts_warmup.py --exe build/dispweave \
  --reference results/crust-nuts-final --output results/nuts-metric-restart-pilot-new \
  --metric-shrinkage 25 --restart-ablation
```

本地证据：`results/nuts-metric-restart-pilot/`。协议在运行前保存二进制、脚本和输入配置哈希。
真实地壳运行的前 100 次进度需与此前普通策略＋k=25 的记录逐字段一致。
历史对照不是同批次配对计时，不据墙钟差异宣称精确加速倍数。
超时只报告已刷盘转移和矩阵决策，目标评估是下界；完成时核对搜索、初始化、预检、
初始 GN 与额外 guard Jacobian 的完整成本。短测不代替四链正式后验验收。

## 结果

仅温和重启时，原初值 0 完成 300 次预热＋33 个正式状态，原初值 1 完成 186 次预热，
均在 120 秒停止；此前普通策略＋k=25 分别只完成 266 / 172 次预热。
在共同进度处，初值 0 的前 266 次转移评估从 12,214 降至 10,384（约少 15.0%）；
初值 1 的前 172 次从 12,013 降至 10,656（约少 11.3%）。不同后续轨迹的转移数不等于 ESS，
因此这些是计算代价对照，不是每个有效后验样本的加速倍数。

初值 0 的首次 100 次中有原策略已有的 2 次发散、1 次数值失败，未被忽略；
第 100 次之后没有新增发散或数值失败。其 33 个正式状态的冻结步长为 0.139675，
平均接受统计为 0.99056，最大树深 6（无深度 10 截断）。初值 1 的已完成转移没有发散或数值失败。

在线矩阵检查的结果：

| 原初值 | 仅温和重启：预热＋正式 | 加矩阵检查：预热＋正式 | 检查的额外 Jacobian |
|---|---:|---:|---:|
| 0 | 300＋33 | 300＋33 | 3 |
| 1 | 186＋0 | 235＋0 | 2 |

初值 0 的第 100 / 150 / 250 次更新均被接受，刚性比分别为 1.7612 / 0.6910 / 0.6844；
两种方案的完整 333 次进度逐字段相同，不能把重复的 33 个正式状态算成独立证据。
初值 1 第 100 次更新被接受（比值 0.4996），第 150 次被拒绝（6.2418 > 4）。
拒绝前的 150 次路径完全一致，拒绝后继续使用旧矩阵和原双平均状态。
随后共同的 36 次转移，开启检查的评估为 2,268，未开启为 5,084。
相对历史普通策略，在前 172 次处，组合方案评估从 12,013 降至 9,120，约少 24.1%。

四次试验的前 100 次都与历史普通策略逐字段一致。第 100 次之后，四次均未观察到
发散或数值失败。组合方案初值 1 尚未到第 250 次窗口更新，因此不能评价最后一个窗口和正式采样。

四次都在 120 秒时限停止，未完成预定的 300＋100。目标转移评估下界分别为
13,069 / 12,818（不检查）、13,069 / 12,865（检查）；检查额外的 3 / 2 次 Jacobian 单独记录。
由于运行中断，完整搜索成本未刷盘，不能把这些下界写成全部目标调用。

## 结论与下一项

分离启动与重启避免了上一轮的启动退化；在线检查也在实际地壳轨迹中阻止了一次
高刚性候选更新，改善了慢初值的预热进度。当前证据支持保留为可选策略，仍不切换默认配置。
尚未证明每单位时间的有效样本数改善，也没有替换 `results/crust-nuts-final/` 的四链正式结果。
下一项应先验证慢初值完成最后窗口后的冻结采样质量，再决定是否做更长的多链效率对照；
不继续扫描当前阈值来追求本次短测的最好数字。
