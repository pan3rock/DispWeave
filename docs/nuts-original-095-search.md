# 原始四初值完整验证：0.95 与合理步长搜索

接续 [固定检查点矩阵对照](nuts-metric-pair.md)，停止增加启发式，验证候选设置从原始初值
出发是否具有实际效率优势。最后一次质量矩阵更新不会因局部最高频率增加而被拒绝。

## 预先固定的协议

- 原四个分散初值、原 seed 20261023、chain ID 0–3、逐初值 GN 初始矩阵。
- slice NUTS、标准 dense 适应、原 1000 次预热窗口与双平均、正式各 1000 状态。
- 与原已验收 0.99 配置相比，只改目标接受率为 0.95、开启 `find_initial_step_size`，
  将正式状态预算从 2000 改为 1000。搜索在首次启动及每次矩阵更新之后执行。
- 数据、协方差、模型、物理 Vs 先验、边界、模态支持域不变；温和重启、协方差延续和刚性保护均未启用。
- 四个数值进程并发，单链最多 1800 秒，无中途调参、重试或预算扩展。
  这是 30 分钟单链上限，不是预期耗时；完成即停止。审计及预测另需少量计算。
- 任一链不完整则不汇总四链 ESS，不替换成较短公共前缀。
- 全部 49 个量要求 R-hat≤1.01、bulk/tail ESS≥400；正式期无发散、数值失败、树深截断或停滞链。
  预定每链第 500 个零基正式状态核查两尺度有限差分及标准/精细正演，每链选 100 状态做预测。

```sh
python scripts/benchmark_nuts_original_starts.py --exe build/dispweave \
  --reference results/crust-nuts-final --output results/nuts-original-095-search-new \
  --with-step-search --timeout 1800
MPLCONFIGDIR=/tmp/dw-matplotlib python scripts/plot_nuts_original_starts.py results/nuts-original-095-search-new
```

历史对照使用原 0.99 的完整 1000 预热＋前 1000 正式状态，重新计算同样样本数的 ESS。
总成本包括初始化、预检、初始 GN、步长搜索和全部转移；不把 2000 状态的旧耗时直接作墙钟对照。
与原完整 2000 状态的后验均值、标准差、分位数另做一致性比较；该比较是描述性的，
同一原始 seed 不意味着改变算法选项后仍是相同动量序列。

## 实际结果

**完整验收通过。** 四链均完成 1000 预热＋1000 正式状态，单链采样约 282–290 秒，
并行采样约 5 分钟；没有用满 30 分钟上限，没有重试。

| 指标 | 原 0.99（前 1000 正式） | 0.95＋搜索 |
|---|---:|---:|
| 总评估，含预热/搜索/初始化 | 377797 | 122950 |
| 正式评估 | 199410 | 59671 |
| 最大 R-hat | 1.00402 | 1.00352 |
| 最低 bulk ESS | 2263.1 | 1695.1 |
| 最低 tail ESS | 1615.3 | 1989.7 |
| 最低 bulk ESS / 千次总评估 | 5.990 | 13.787 |
| 最低 tail ESS / 千次总评估 | 4.276 | 16.183 |

总评估减少约 67.5%；包含预热的最低 bulk ESS/成本提高 **2.30 倍**、最低 tail ESS/成本
提高 **3.79 倍**。相同状态数下 bulk ESS 本身没有增加，收益来自计算成本下降更多。
49 个量逐一计算的 bulk/tail ESS/总成本在本次均改善，bulk 比值中位数 2.56、tail 中位数 3.05。
不能把这些评估效率比直接称为历史墙钟加速倍数，旧运行没有相同前缀的墙钟记录。

正式期无发散、数值失败、树深截断；链 3 有 1 次合法支持域拒绝。
预热发散分别为 2/5/6/3，数值失败为 1/2/2/1；搜索并未消除所有预热不稳定性。

## 后验与数值核查

- 所有 49 个量通过预定完整链混合门槛；正式期数值诊断通过。
- 每链预定中间状态的两尺度有限差分及精细正演核查全部通过。
- 400 个后验预测状态全部有效，预测检验 p≈0.515；125 个观测中 121 个位于逐点 95% 预测区间内。
  这是模型检验摘要，不是同时置信覆盖证明。
- 相对原完整 4×2000 后验，49 个量标准差比范围 0.964–1.061；分位数最大差异约 0.175 个
  原后验标准差，均值最大差异约 2.32 个合并 Monte Carlo 标准误。这是多量描述性核查，
  未作严格分布等价检验，也没有据比较结果调整先验或采样参数。
- 前后各 500 状态的最低 bulk ESS 为 835.7 / 723.8；最大 R-hat 为 1.0071 / 1.0134。
  后半段单独仍略超 1.01，说明有限样本诊断有波动；正式验收按预先声明的完整 1000 状态。

## 本算例的推荐设置

本轮支持将下面设置作为**本算例后续运行的推荐选项**，保留标准 dense 适应及逐初值 GN：

```toml
[nuts]
kernel = "slice"
target_accept = 0.95
find_initial_step_size = true
metric_adaptation = "dense"
initial_metric = "start_gauss_newton"
```

这只是 `[nuts]` 的关键选项片段，完整配置仍需原先验、种子与采样预算。
不更改库级默认值，不覆盖原已验收 0.99 后验。
本轮同时改变接受率与搜索选项，不能把整体收益全部归因于其中一个；矩阵随路径改变也是
实际流程的一部分。只有一个原始 seed 的完整对照，不证明对其他模型或随机流都最优。
至此已得到完整流程收益证据，可停止本轮内核启发式优化，把该配置作为后续实际使用的基线。
