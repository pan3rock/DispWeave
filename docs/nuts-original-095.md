# 原始四初值：slice NUTS 目标接受率 0.95

本轮接续 [固定矩阵较长确认](nuts-step-size-confirmation.md)，检验降低目标接受率能否改善
从原始分散初值开始的在线适应。恢复原来的密集质量适应，覆盖此前开销最大的 450–950 窗口。
生产采样器没有修改，没有启用现代内核或新增预热保护选项。

## 固定协议

- 四个原始 Vs 初值，seed 20261023，chain ID 0–3。与已验收 `crust-nuts-final` 的配置相比，
  只将目标接受率 0.99 改成 0.95，并把正式预算从 2000 缩至 1000；预热仍为 1000 次。
- slice 内核，逐初值 Gauss–Newton 初始质量矩阵，原 dense 协方差适应与双平均。
  初始步长 0.1，最大树深 10。初始步长搜索、协方差延续、温和重启和矩阵检查均保持关闭。
- 原模型、45 个自由 Vs、125 个观测及数据协方差、物理先验、边界和模态支持域不变。
- 四个数值采样进程并行，每条最多 600 秒，采样墙钟总预算约 10 分钟。不重试、不延长、不丢弃慢链。
  有任一链不完整则不汇总 pooled ESS，不标记验收通过。
- 若四链完成，沿用原验收逻辑：49 个参数与派生量 R-hat≤1.01、bulk/tail ESS≥400，
  正式期无发散、数值失败或树深截断；每链预定中间状态做两尺度有限差分及精细正演核查，
  另从各链等距选择 100 个状态做后验预测，要求全部有效。

## 链 0 为什么变慢：最后一次矩阵更新是明确检查点

950 次更新前，末 50 次平均接受统计为 0.947；更新后的首两次接受统计为 0.170 和约 0，
随后双平均降低步长。950–1000 的 50 次共花费 4384 次评估。
正式期冻结步长 0.06132，已完成 641 次的平均接受统计为 0.963，接近目标 0.95；
不能仅凭步长数值小，就认为双平均把它压得过小。

补充诊断从 progress 重建更新前后矩阵，在保存的第 949、999 个零基状态各做一次初始 GN
评估（各一个极小步长的单步诊断，非新增正式链）。相同位置下，更新后局部最高频率平方
分别增为 4.21、3.78 倍，对应谐波稳定步长上限分别从 0.302→0.147、0.379→0.195。
但局部条件数同时从 4051→560、2561→344，意味着最慢方向也明显改善，不能据最高频率
增大就断言矩阵质量退化。矩阵重建公式另与三条完整链保存的最终矩阵独立核对一致。

这是两个位置的 **Gauss–Newton 曲率近似**，不是精确 Hessian，也不是小步长原因的充分证明。
证据及诊断脚本保存在 `last-metric-audit/`。结果说明应把矩阵变化与步长重适应联动考察，
而不是继续单独降低目标接受率，或根据两个局部点直接增加拒绝矩阵的规则。

下一步宜固定链 0 最后更新后的矩阵及检查点，在相同初值、相同评估预算下比较现有冻结步长
与重新适应步长，检查接受统计、发散和有效移动；先判断重适应是否能解决问题，再决定是否
需要改质量适应。本轮仅记录这一后续方案，未启动新一轮采样。
