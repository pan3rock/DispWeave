# 固定质量矩阵的步长目标对照

本轮按照“先隔离步长问题，再判断整体收益”进行对照，不再增加预热启发式规则。
固定质量矩阵和后验起点，只比较 slice / multinomial 内核及目标接受率 0.90 / 0.95 / 0.99。
生产采样器没有修改，运行二进制对应 `6d4248a`。

## 运行前固定的协议

- 共六组，每组四条链。从已验收四链的各自最后一个物理 Vs 状态启动；共用已验收 chain 0
  的最终动量质量矩阵和初始步长 0.1349601055。该矩阵也是此前内核短测使用的矩阵，非本轮择优所得。
- 每条链 100 次双平均步长适应＋200 个正式状态。固定 seed 20261024、chain ID 0–3、最大树深 10。
  关闭质量适应、初始步长搜索、协方差延续、温和预热/重启和矩阵检查。
- 45 个自由 Vs、125 个观测、固定数据协方差、物理 Vs 高斯先验及受俘获模态支持域均不变。
  `model.vs` 仍是原先验中心，只替换 `inversion.starts_vs`，不把后验起点变成新的先验。
- 四个数值采样进程并行，六组运行顺序在四个起点间轮换。单链最多 150 秒，总墙钟硬预算约 15 分钟。
  不重试、不加预算、不删除失败链、不把不完整组裁成相同长度后计算 ESS。
- 所有参数及四个派生量（0–20、20–100、100–208.925 km 平均 Vs 与参考先验二次型）均参与诊断，
  不按结果挑选混合好的层。ESS 保留全部正式状态，包括重复状态。

`results/nuts-step-size-pilot/` 保存运行前协议、输入/配置/脚本/二进制哈希和冻结副本。
原始数据、先验、公共起点及固定矩阵另做独立核对；同一内核/起点的第一步在三个目标下须逐字段相同，
保证目标接受率只从后续步长适应开始影响路径。

python scripts/benchmark_nuts_step_size.py --exe build/dispweave \

MPLCONFIGDIR=/tmp/dw-matplotlib python scripts/plot_nuts_step_size.py results/nuts-step-size-pilot-new

## 指标与解释

主要报告最低 bulk/tail ESS、最大 rank/folded split R-hat、正式期数值失败/发散/树深截断，
并比较 ESS/正式目标评估、ESS/包含适应的总评估、ESS/包含适应的累计链时间。
累计链时间是各链墙钟之和，不是整批并行运行的墙钟，也不是仅正式采样的计时。
支持域拒绝单独记录，不当作数值失败，也不删除该次状态。

每条链只有 200 个正式状态，ESS 是探索性估计。预先规定额外查看前/后各 100 状态的诊断，
以及全部观测量的效率比；半段结果和相关参数间的分位数都不是置信区间。
与原 4×2000 后验比较均值及合并 MCSE；由于复用了起点、且有 49 个相关比较，
这只是描述性核查，不是独立检验或覆盖率证明。

## 实测结果

24 条链全部完成，没有超时或补跑，每组 800 个正式状态，共 4,800 个正式状态。
六组正式期均无数值失败、发散或树深截断。slice 的 0.90 / 0.99 各有 1 次支持域拒绝，
multinomial 的 0.95 有 2 次，其余为 0，均保留在轨迹和成本中。

目标接受率和有限样本的实际平均接受统计不同：slice 三组分别为 0.9134 / 0.9563 / 0.9841，
multinomial 为 0.9184 / 0.9562 / 0.9848。固定 100 次适应并不保证恰好达到目标值。
multinomial 的 0.90 组虽然步长更大，平均评估/状态略多于其 0.95 组，
因此不能只凭步长或树深推断效率；此处优势来自实际 ESS/成本。

预热也如实计入：slice 三组均无预热发散或数值失败；multinomial 三组分别有
4 / 3 / 3 次预热发散，数值失败均为 0。正式稳定不代表预热全程无异常。
累计链时间分别为 146.18 / 178.73 / 358.04 秒（slice）和
182.80 / 190.90 / 379.05 秒（multinomial）。这些时间包含全部 100 次适应开销。

## 效率比与短链敏感性

下表均以同一内核的 0.99 为 1，前后半段分别重新计算最低 bulk ESS 与对应正式评估数。

| 方案 | bulk ESS / 正式评估 | bulk ESS / 总评估 | bulk ESS / 累计秒 | tail ESS / 正式评估 | 前 / 后半段 bulk 效率比 |
|---|---:|---:|---:|---:|---:|
| slice 0.90 | 1.84 | 1.93 | 1.95 | 1.81 | 1.37 / 4.25 |
| slice 0.95 | 1.96 | 1.97 | 1.96 | 2.03 | 0.96 / 4.64 |
| multinomial 0.90 | 2.30 | 2.46 | 2.46 | 1.83 | 2.26 / 1.97 |
| multinomial 0.95 | 1.96 | 1.97 | 1.93 | 1.94 | 1.85 / 2.06 |

multinomial 0.90 的 49 个观测量，逐项 bulk ESS/正式评估比的最小值、四分位数、中位数、
上四分位数、最大值为 1.37 / 1.88 / 2.20 / 2.51 / 3.47；收益不只来自某个最差层的更换。
但这些量高度相关，不能当作 49 个独立重复试验或统计显著性证据。
slice 0.95 的半段结果明显不稳定，不能把整段的近两倍收益当作精确可重复倍数。


## 结论

本轮支持此前的判断：在这套已适应的固定矩阵与后验区域内，目标 0.99 带来的小步长
明显增加成本，未观察到相应的有效样本收益。降低至 0.90/0.95 的收益同时体现在两种内核，
因此优先检验步长目标比继续叠加预热保护规则更有依据。

现代内核 0.90 在本轮 bulk 效率上表现最好，值得作为下一轮候选；原 slice 只改目标到 0.95
也出现约两倍的整段效率估计，因此不能把收益全部归因于“现代内核”。bulk 与 tail 排名也不完全相同。

所有组的最大 R-hat 仍高于 1.01，且每链仅 200 状态；没有新的后验验收通过。
尚未测试原始分散初值、在线质量适应、原慢链的质量矩阵或第 450–950 次窗口，
不能由此证明从头反演的总耗时会减少相同倍数，亦不能证明 0.90 普遍最优。
保持默认配置及已验收的四链后验不变。下一步应对候选 0.90/0.95 做更长的正式质量验证，
再检验其在原始初值下的完整流程；本轮不再增加新的步长启发式或临时放宽数值失败标准。

后续已完成新种子的 [4×1000 状态确认](nuts-step-size-confirmation.md)：两候选均通过固定矩阵
条件诊断，但长链最低 bulk 效率排序与本轮短测不同，不沿用短测赢家结论。
