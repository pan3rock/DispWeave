## 实现：改变提议，不改变目标分布

对每个 K，坐标为 `x=[z1,...,z(K-1),Vs1,...,VsK]`，维数 2K−1。
使用冻结的多元 Gaussian 混合 `q_K(x)` 同时更新所有界面和速度，K 保持不变。
直接使用物理坐标，未引入变量变换或额外 Jacobian。

在温度 T 下，接受 log 比为：

`(logL(new)-logL(old))/T + logPrior(new)-logPrior(old) + log q_K(old)-log q_K(new)`。

计算的是**全部混合分量求和后的密度**，不是本次抽中的分量密度。只有似然加温，
先验和 q 比都不加温。协方差 Cholesky、权重归一化和 log-sum-exp 在固定密度下计算。

密度定义于整个物理坐标空间；生成的界面无序、厚度不足或速度越界时，
一次拒绝且不正演，不排序、不裁剪、不重抽。因此没有漏掉截断归一化因子。
失败正演仍记录并拒绝。birth/death 的映射、先验和接受比保持原样。

CLI 开关为 `[rjmcmc] correlated_probability=0.4`，默认 0。
它是原 25% 速度动作内部的条件概率，所以本轮总动作比例为：
birth 25%、death 25%、单界面 25%、单速度 15%、相关联合 10%。
前轮 `velocity_refresh_probability` 保持 0，未叠加宽先验重抽或冷启动。
两个可选概率之和不得大于 1。轨迹独立记录 `correlated` 动作。

配置通过 `[[rj_correlated_models]]` 指定 K，并在其 `components` 中提供 weight、mean 和完整 covariance。
启用时必须为先验范围内每个 K 提供恰好一个混合密度；输入需维度正确、均值有限、
权重正且有限、协方差对称正定。不存在运行中学习或修改分量的接口。

## 如何使用旧样本

训练只使用原直接 PT 的四条冷链，即 `results/rj-pt-transdim` 中的 100000 个正式状态。
这些旧样本**仍未验收**，这里只用于形成一个可计算的提议密度，未当作可靠后验或新样本。
K 的先验概率未根据这些样本修改。

方案在拟合前写入 `design.json`，没有尝试多个分组/收缩参数：

- K=2/3/4：各旧链在对应 K 下的全部样本分别形成一个经验分量，保留重复状态；四分量权重各 0.225。
- 协方差固定为 `0.9 S + 0.1 diag(S) + 1e-6 diag(scale²)`，其中界面 scale=5 km、Vs scale=1.9 km/s。
- 另加权重 0.1 的宽 Gaussian，中心为等间隔界面与速度先验中点，方差为相应范围平方/12。
  它提供较宽覆盖，降低经验分量过窄的风险；不能保证覆盖所有重要后验结构。
- K=1 没有旧正式样本，使用上述宽 Gaussian 作为唯一分量，权重 1。

得到 K=2/3/4 各五个分量、K=1 一个分量；12 个经验协方差已用独立矩阵表达式重算核对。
分量一经写入配置，即在全部预热和正式阶段冻结，四个独立梯共用同一组 q，但使用不同随机流。
这是一种借鉴开源 ensemble/data-informed 思想的简单实现，不是直接移植 Eryn 的 group move。

## 固定预算结果

数据、物性、先验、困难起点、种子、局部步幅、温度 1/2/4/8 和交换间隔均保持。
四梯×四温度，每副本 2500 预热＋25000 正式，共 **440000 次局部提议**。
一次运行完成，没有延长链、重新训练或扫描提议比例。

| 指标 | 原直接 PT | 冻结相关联合 PT |
|---|---:|---:|
| 本次总目标评估 | 400546 | 393653 |
| K=2 R-hat | 1.00466 | 1.01364 |
| K=2 bulk ESS | 866.6 | 910.4 |
| 深度最大 R-hat | 1.01616 | 1.01300 |
| 深度最低 bulk ESS | 251.7 | 968.5 |
| 深度最低 tail ESS | 300.4 | 715.8 |
| 未达标深度点 / 31 | 13 | 1 |
| 全温度正式正演失败 / 评估 | 18389 / 365189 | 14244 / 357833 |
| 全温度正式正演失败率 | 5.04% | 3.98% |

31 个深度点的 bulk/tail ESS 均超过 400；仅 1.667 km 的 R-hat=1.01300 未达标。
K=2 四链观测比例为 53.104%、40.556%、37.248%、38.628%，差异仍需保留；
K=3/4 指示量通过，K=1 未访问，仍保留 constant_chain，不能认证精确零概率。
正式无 numerical_failure，但 missing_or_unresolved 正演限制仍未解除。

四梯均完成温度往返，每副本 61–77 次；原来的第 0 梯最热端隔离没有复现。
采样和输出约 29.33 秒，期间另有编译任务，不作墙钟加速比结论。

## 联合提议确实更有效，但要计入旧样本成本

正式期 40088 次联合提议中，**8353 次接受（20.84%）**；其中 8072 次越界，未调用正演，
其余 32016 次目标评估中有 705 次正演未解析。所有接受事件都同时改变界面和速度。

| 温度 | 联合提议 | 接受 |
|---|---:|---:|
| 1 | 10033 | 3193 |
| 2 | 9998 | 2597 |
| 4 | 10056 | 1576 |
| 8 | 10001 | 987 |

对照前轮宽先验整组 Vs 重抽的 0.157%，说明利用界面—速度相关结构确有作用。
新轨迹中记录到 8 次联合更新将原始 logL 从小于−50提高到大于0，含一次正式期热链事件；
例如第 0 梯 T=8 的 iteration=22267 从 −85.70 到 11.74。
这些阈值仅描述拟合跃迁，不是后验模态的定义或完整脱困证明。

训练样本不能当成免费资源：

- 本轮新采样：393653 次目标评估。
- 生成所用旧 PT 样本：400546 次目标评估。
- 从零生成旧样本再运行本方案：合计 **794199 次**。
- 本轮准备/拟合约 0.21 秒；另行审计正演属于验证开销，单列且不混入采样比较。

以最低深度 bulk ESS/总评估计算，复用已有样本时约为原 PT 的 3.9 倍；
计入旧样本生成成本后约为 1.9 倍。由于部分 R-hat 仍未通过且仅有一次对照，
这些是诊断效率估计，不是可靠样本吞吐或通用加速保证。
旧样本没有并入新后验统计。

## 验证与复现

- Release CTest **80/80**；UBSan 定向测试 **3/3**。
- 混合密度归一化、正反接受比、越界不重抽、非法协方差/配置、不同温度的解析均值和非均匀 K 先验分布通过。
- 默认选项下与冻结旧 PT 的短程结果 78 个文件逐字节一致；启用相关提议时，
  冻结实验二进制与最终配置解析写法的短程结果 94 个文件逐字节一致。
- 400000 个各温度正式模型、440000 条转换、40016 个含初值预热状态、失败编号与缓存核对通过。
- 用 NumPy 逆矩阵/行列式独立计算完整 Gaussian 混合密度，重算全部已接受相关更新；
  接受 log 比最大差 2.85e-14。正反 q 差保持不加温。
- 全部层数/深度诊断独立重算；48 个正式及 16 个预热末状态重新正演，
  归一化似然最大差小于 5.70e-11。原训练文件 hash 和固定提议配置 hash 未改变。

保留为默认关闭的候选：方向有实质收益，但本轮不自动叠加新机制、调权重或延长链。
剩余重点是 K=2 占比的链间差异及主界面附近速度的一致性，而不是再次扩大整体速度随机扰动。
