## 提议和接受比

保持 K 和全部界面不变，同时独立提出所有 Vs：

`Vs'_j ~ Uniform(vs_lower, vs_upper), j=1..K`。

条件提议密度为 `q(Vs'|Vs,K,z)=width^(-K)`，正反密度相同，Jacobian=1。
混合权重不依赖状态，因此接受 log 比为

`(logL(new)-logL(old))/T + logPrior(new)-logPrior(old)`。

当前固定 K、界面下的 Vs 先验是独立均匀分布，先验差也为零；实现仍保留通用的先验差计算。
这只是宽先验内的独立联合提议，不包含学习协方差、后验拟合、LM/NUTS 或梯度。
无效正演仍记录并拒绝。不会删除观测、截断速度到边界或重试直到有效。

可选配置在 `[rjmcmc]` 下，默认 `velocity_refresh_probability=0`：

```toml
[rjmcmc]
velocity_refresh_probability = 0.4
```

此数值是**已经选中原速度动作之后的条件概率**。birth/death/interface 三种动作仍各 25%；
原速度动作占 25%，其中 40% 使用联合提议。因此本实验的总动作比例为：
birth 25%、death 25%、interface 25%、单坐标速度 15%、联合速度 10%。
联合动作单独标为 `velocity_refresh`，CLI、PT 统计和普通 RJ 诊断都记录它。
关闭时不新增随机数抽取，默认旧轨迹保持。

## 先验证，再运行实际对照

纯提议测试核对支持域、固定界面/层数、正反密度和详细平衡。
解析例子使用两个反相关速度峰，权重为 0.25/0.75；三个种子各 5000 预热＋400000 正式，
观测较大权重峰比例为 0.7534、0.73865、0.73284，批次 MCSE 为 0.01154、0.01032、0.01337，
均在 6 MCSE 内，且各有 1303–1460 次由联合提议产生的峰间转换。

初版使用 100000 样本和固定比例容差，因未计入自相关的 Monte Carlo 误差而失败；
改为 40 个长批次估计 MCSE，并要求 MCSE<0.03、误差<max(0.005,6 MCSE)，
同时核对均值和实际动作频率。该调整只用于解析单元测试，实际反演仍只运行一次，
并保留原诊断门槛，未为放行反演结果改变标准。

另外验证非均匀 K 先验在各温度下的解析层数分布，以及刷新后正演失败的拒绝行为。
Release CTest **79/79** 通过，UBSan 定向测试 **3/3** 通过。
默认配置与冻结旧 PT 二进制的短程运行有 78 个输出文件逐字节相同（耗时 metadata 除外）。

## 实际对照预算

回到原直接 PT，**不叠加前轮失败的 500 步冷启动**。原 K=1–4、四困难起点、数据、
先验、物性、温度 1/2/4/8、每 10 步交换、局部步幅和随机种子保持。
每副本 2500 预热＋25000 正式，四梯共 **440000 次局部提议**。
开启完整预热记录；它已验证不改变随机轨迹。

唯一提议干预是上述固定比例联合更新。配置和 hash 在采样前保存，不扫描比例，不延长链。
相同种子下新动作会改变随机数消费及后续轨迹，不能视为逐步一一配对的因果对照。

| 指标 | 原直接 PT | 加联合 Vs 提议 |
|---|---:|---:|
| 总目标评估（包括全部温度和预热） | 400546 | 399182 |
| K=2 R-hat | 1.00466 | 1.00628 |
| K=2 bulk ESS | 866.6 | 488.4 |
| 深度最大 R-hat | 1.01616 | 1.01683 |
| 深度最低 bulk / tail ESS | 251.7 / 300.4 | 373.6 / 260.2 |
| 未达标深度点 / 31 | 13 | 11 |
| 第 0 梯正式期 T=4↔8 交换率 | 0 | 59.2% |
| 正式正演失败 / 评估 | 18389 / 365189 | 29335 / 364371 |
| 正式正演失败率 | 5.04% | 8.05% |

K=2/3/4 指示量仍通过，K=1 未访问；深度统计未全部达到 R-hat≤1.01、bulk/tail ESS≥400。
总目标调用接近，不能把部分 ESS 改善概括为整体提速。采样与输出约 32.22 秒，
另有编译任务同时进行，不比较墙钟速度。

## 为什么不采用

正式期共 40053 次联合提议，仅接受 **63 次（0.157%）**：

| 温度 | 提议次数 | 接受次数 |
|---|---:|---:|
| 1 | 10014 | 5 |
| 2 | 10018 | 3 |
| 4 | 10075 | 19 |
| 8 | 9946 | 36 |

其中 15849 次（39.57%）出现未解析正演；其余动作合计正式失败率约 4.16%。
宽先验独立重抽在这个数据约束下很少落到可接受区域，是明确的成本问题。
预热另有 3890 次联合提议，接受 12 次。

四梯所有副本完成 48–79 次正式冷→热→冷往返；本轮没有复现原来的热端隔离。
但记录中没有联合更新直接将原始 logL 从小于−50跃迁到大于0的事件，
不能声称已证明联合提议直接“救出同一条坏链”。这些阈值只用于描述事件，不是模态定义。
新轨迹的预热情况和交换路径均已改变；一次实验不足以证明稳定改善。

## 独立核查与停止边界

全部联合接受事件核对固定 K/界面、所有 Vs 同时改变、未加温先验、零 Hastings 修正和接受比。
正式期 86873 次可检查的已接受转换、400000 个保留模型、440000 条转换记录，以及全部诊断核查通过。
预热 40016 个含初值状态、9116 次接受和 30884 次拒绝亦通过独立核对。
重算 48 个正式状态及 16 个预热末状态的原始似然，误差均小于 8.76e-11。
所有失败仍保留为 `missing_or_unresolved`，没有独立依据时不改称纯物理无根。

联合提议实现保留为默认关闭的研究选项；本轮结果保留为未验收对照。
