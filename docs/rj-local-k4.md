# 固定 K=4 局部相关更新：接受率提高，整体探索变差

**完成实现、验证和一次预定尺度的对照；本次局部方案不采用为推荐配置。**
局部移动确实降低了越界与拟合损失，但没有解决结构之间的探索，反而使关键诊断变差。
这否定的是“用当前尺度的局部更新替换独立联合更新就能改善本算例”的假设，
不证明所有局部相关方法都无效。本轮不扫描尺度、不追加运行，也不同时改birth/death。

## 实现和目标分布

新增 `[rjmcmc] correlated_local_scale`，默认0保持原独立Gaussian混合提议；
正值启用局部模式，本轮只使用 **0.2**，未调参。
两组使用低速夹层新预运行得到的同一套K=4分量、权重与协方差，不重新训练。

局部模式为 `y=x+s L_j ε`，其中 `ε~N(0,I)`，`j` 按冻结且与状态无关的权重选择，
`s=0.2`、`L_j L_jᵀ=Σ_j`。原拟合分量的均值不用于局部位移。
因此完整混合 `q(y|x)=Σ_j w_j N(y−x;0,s²Σ_j)` 对称，正反q比精确抵消。
这依赖于权重/协方差固定，不能推广到按当前位置选择分量或在线改变协方差的算法。
边界外只拒绝一次，不排序、裁剪、截断或重抽，没有额外Jacobian。

温度目标仍是 `prior × likelihood^(1/T)`；只有似然加温。
trace仍标记correlated，配置与metadata明确区分独立/局部模式。
非法尺度与未启用联合动作却设置局部尺度的配置会被拒绝。

## 严格区分固定层数与原跨维问题

两组均将原先验**条件化到K=4**，界面、Vs、物性和观测不变。
四个历史固定K=4起点完全相同，没有选择接近真值或较好拟合的起点。
温度1/2/4/8、每副本2500预热＋25000正式、四梯、交换间隔10均不变。
同一预定种子2026102901用于两组，不把它们说成独立复验。

每组 **440000次提议**，动作概率保持：25%不可用birth、25%不可用death、25%单界面、
15%单速度、10%联合。不可用动作保留为自转移，没有重归一化。
这是相同提议预算，不是相同实际正演次数；后者单列，并比较ESS/目标评估。
原K=1–4结果与这里不是同一个目标，不能拿两者的层数占比或接受率直接作改善结论。

固定K的验收检查七个物理参数和31个深度点，常数K指示量不用于判定失败。
另外检查低速层事件、深度速度反差以及低速层处于不同内部位置的指示量，防止只看接受率。

## 更关键的失败：不同结构表示没有充分交换

沿用此前低速层定义：至少比左右邻层低0.1 km/s，多个候选时取最强者。
“最强低速层位于第二个内部位置”的指示量在全部状态上计算，不压缩时间序列；
没有低速层的状态记为0。

| 指标 | 独立联合 | 局部相关 |
|---|---:|---:|
| 该结构指示量R-hat | 1.07916 | **1.24175** |
| bulk ESS | 52.81 | **12.86** |
| 四链观测比例 | 12.08 / 6.99 / 1.65 / 14.00% | **1.12 / 0 / 40.83 / 0.60%** |

局部模式有一条链该指示量恒为0，保留constant_chain警告；其R-hat数字不能覆盖此限制。
相比之下，“存在任意低速夹层”这一粗粒度事件在局部模式下R-hat≈1.00316，
看起来较好，却掩盖了内部位置表示的严重差异。

因此这次实验更支持：**减小移动、保留局部拟合，不足以保证跨结构探索**。
不把一个尺度的一次运行解释为确定的因果定律，但现有证据已足够拒绝直接采用该替换方案。
下一项若继续，应针对不同低速层表示之间的连通性提出可检验方案；
本轮不自动增加混合比例、调整尺度或扩展成新的跨维算法。

## 验证与成本

- Release CTest **81/81**通过；UBSan定向测试 **3/3**通过。
- 新测试覆盖零均值混合增量协方差、分量均值不影响局部移动、边界不重抽、
  对称接受比、不同温度解析均值、非均匀K先验及非法配置。
- 默认独立模式与原冻结二进制短程对照，**95个文件逐字节一致**，不含计时metadata。
- 两组各440000步提议全部重建；接受及失败候选坐标最大误差0。
  独立/局部模式分别核对85511/98218个接受状态，接受似然分解误差≤7.11e−15。
- 两组正式、预热、失败编号、交换、K/深度诊断及物理参数独立核对通过；
  128个模型似然复算最大差<8.32e−11。
- 审计脚本最初发生配置变量重名，已修正并保留中断记录；修正重做审计多用了3个模型正演。
  **科学采样没有重跑**，审计实际成本为131个模型正演。

本次两组新采样共 **389208次目标评估**；加共享旧预运行成本371844次，总计 **761052次**。
旧预运行只计一次，没有新拟合；之前为定位问题运行的跨维正式实验不属于本次配对比较。
默认行为短程回放另有4262次目标评估；单位测试和上述审计是验证开销，未混入两组科学预算。
采样写出分别约23.41、23.67秒，期间存在编译/分析任务，不据此比较墙钟速度。

功能保留为**默认关闭的实验选项**，原独立提议推荐状态不变；不宣称此次优化成功。
