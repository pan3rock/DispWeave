# 三层低速夹层：固定预算迁移验证

**当前方法能恢复本算例的低速夹层特征，但相同预算下的定量后验没有通过验收。**
新算例的相关联合提议仍改善了部分深度混合，不过收益明显弱于此前两层算例。
本轮没有追加运行、换种子、改变噪声、调温度或调提议比例；不能将此结果描述为稳定泛化已完成。

## 新算例与可辨认性检查

目标为三层模型，层顶深度 [0, 0.8, 1.8] km，Vs=[1.6, 1.0, 2.3] km/s，末层半空间。
Vp/Vs=1.8、密度2.3、12个0.15–0.9 Hz基阶频率、σ=0.03 km/s沿用前例。
噪声只生成一次，种子2026102800。K=1–4等权先验、0–5 km界面范围、0.3 km最小间距、
Vs范围0.8–2.7及四个原有困难起点不变，起点不注入新真值。

在采样前先做两项固定对照：

1. 将夹层Vs从1.0填为1.6，其他条件不变。与真值曲线的白化差平方和为 **1695.3**，
   单频最大差约18.1σ。这说明低速层对该对照确实产生强信号。
2. 用界面固定在1.8 km的两层模型、四个既有初值，对**无噪声真值曲线**做无正则化LM。
   最佳残差平方和仍为 **103.6**，所以这个受限的简化模型不能完全吸收差异。

上述量是无噪声曲线距离，不是统计p值；没有穷尽所有无低速层模型，也没有优化两层界面位置。
因此这里只能说对预设对照可辨，不能证明全局结构唯一。没有按检查结果筛选或调整算例。
这个LM对照拟合的是无噪声真值，不能与另一个算例拟合含噪观测的LM χ²直接比较。

## 新样本训练新提议，完整计入成本

使用前例冻结的同一可执行文件，两阶段均为四梯×T=[1,2,4,8]，
每副本2500预热＋25000正式，每阶段 **440000次提议**，交换间隔10。

- 新预运行：普通PT，种子2026102801，不启用相关联合提议。
- 正式验证：仅用本次预运行冷链拟合q，种子2026102802；相关联合动作仍占总动作10%。
- 从未读取两层算例样本来训练，也没有将预运行样本并入正式后验。

仍使用每K、每条冷链的经验Gaussian分量和宽防御分量；协方差公式、尺度与前例一致。
为处理新算例的稀少K，预先规定：只有样本数大于维数2K−1的链形成经验分量，
经验总权重0.9在合格链间均分，宽分量权重0.1；无合格链时仅用宽分量、权重1。
没有按拟合质量筛选分量，也没有把样本数阈值当作有效样本数保证。

实际K=1无样本；K=2仅第0链有18个状态，因此只有一个经验分量；
K=3/4各有四个经验分量，共9个。稀少K=2的经验协方差不能视为可靠后验估计，
正定收缩和宽分量仅保证提议可计算与较宽覆盖。全部q在正式运行前冻结，完整q比照常进入接受概率。

## 识别到了低速层，但参数仍未混合充分

预先定义的低速层事件是：至少一个内部层的Vs比左右相邻层均低至少0.1 km/s。
如果有多个，条件位置摘要取邻层最小反差最大的那个；事件统计使用所有状态。

| 指标 | 新预运行 | 冻结q正式验证 |
|---|---:|---:|
| 含上述低速夹层的观测比例 | 98.213% | 98.262% |
| 低速层事件 R-hat / bulk ESS | 1.00575 / 1449 | 1.00487 / 1202 |
| K=3 / K=4 占比 | 34.410 / 65.572% | 33.135 / 66.865% |
| K=3 R-hat | 1.00297 | 1.01488 |
| 深度最大 R-hat | 1.17354 | 1.04958 |
| 深度最低 bulk / tail ESS | 16.0 / 36.6 | 162.3 / 63.8 |
| 深度诊断通过 | 0/31 | 3/31 |
| 正式期全温度正演失败 | 25509 / 336759 | 24811 / 327738 |
| 正式期正演失败率 | 7.57% | 7.57% |
| numerical_failure | 0 | 0 |

正式验证的联合提议接受 **1510/39998=3.78%**，此前两层算例约20%；说明同一种
按K的Gaussian混合提议在复杂结构中的效率不能照搬。温度交换仍连通，没有零往返的副本；
不能把剩余问题简单归因为某一温度完全隔离。

在存在低速层的状态中，正式验证给出的条件摘要为：

| 量 | 目标 | 样本中位数 | 样本2.5–97.5%区间 |
|---|---:|---:|---:|
| 夹层顶部 km | 0.8 | 0.803 | [0.409, 1.234] |
| 夹层底部 km | 1.8 | 1.785 | [1.256, 2.265] |
| 夹层Vs km/s | 1.0 | 0.978 | [0.806, 1.181] |

这些是未完全收敛样本的条件描述，不能用中位数接近真值或区间包含真值宣称定量恢复可靠。
夹层Vs下端接近0.8的先验下界，区间也受先验范围影响。

另用不随层数改变的深度对照：Vs(0.4)−Vs(1.2)和Vs(2.5)−Vs(1.2)。
正式期两者均大于0.1的比例约93.45%，但事件R-hat≈1.03070；
两项反差的R-hat分别约1.04699与1.01015，bulk ESS约200和272。
因此“存在某个低速层”的粗粒度事件较稳定，并不等于低速层的位置和强度已经稳定。

K=4占多数不单独作为失败判据：额外层可与相近频散响应共存，未要求P(K=3)接近1。
但K=4又是本次先验上限，当前层数占比不能外推到允许更多层的先验。
正式期K=1/2均未访问，不能认证其精确零概率；预运行K=2仅18个状态且其余链常数，
即使数字R-hat看起来较小，也保持constant_chain警告。

## 数据拟合与结构辨认分开看

正式冷链每条固定取100个等间隔状态，共400个做后验预测，没有筛选或补抽。
全部正演成功，12/12观测位于逐点95%含噪预测区间内，12/12目标频散点位于latent区间内；
平均观测χ²≈11.84，描述性后验预测p≈0.488。
这表明当前样本能解释数据，但不是留出验证、覆盖率校准或收敛证明。
所选保留状态预测成功也不能消除采样中未解析候选的正演失败限制。

本轮得到的迁移结论是：**可以探索并恢复非单调速度结构，但还不能保证相同预算下得到可靠的完整定量后验。**
不将两层算例的表现推广为通用稳定性结论，也不在本轮继续堆叠机制。
若后续继续，优先定位这个新算例的层内参数相关性和结构模态，再决定是否值得改提议；
不能把高拟合度或98%的事件比例直接当作完成验收。

## 验证、成本与复现

- 新预运行371844次、正式验证361454次目标评估，合计 **733298次**；预运行没有当免费资源。
- 两次采样及写出约33.03和32.63秒；统计、审计另计，不作严格墙钟效率对比。
- 另有400个预测模型、2个前置信号对照正演、60次无噪声LM目标评估。
- 两阶段各核查48个正式＋16个预热模型，共128个审计正演，单列于采样预算之外。
- 两阶段正式与预热接受比、状态/交换/失败记录和K/深度诊断核对；重算似然最大差小于1.42e−10。
- 独立重算9个经验分量、宽分量、训练输入hash、完整配置变化、低速层事件与条件位置和400个预测索引，通过。
- 通用PT分析新增“无旧算例基准”入口，避免新旧数据串比；目标剖面从当前真值读取。
  在临时目录重算原两层实验，summary与原文件完全相同，没有重新采样。
- C++内核不变；保留根完整性、未访问K和未收敛限制。
