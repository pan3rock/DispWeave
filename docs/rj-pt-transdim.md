## 设计与成本

使用原 `results/rj-nuts-comparison` 的观测、协方差、物性、K=1–4 归一化先验、四起点和随机种子。
Vs 步幅 0.08、界面步幅 0.2，birth/death/interface/velocity 仍各 1/4。
唯一采样设置变化是加入固定温度 1/2/4/8，每 10 步交替交换，以及相应分配预算：
四组独立梯，每温度 2500 预热＋25000 正式；总局部提议 440000，与原四链各
10000 预热＋100000 正式相同。各梯的指定起点复制给该梯四温度，未另选热链起点。

协议与输入/二进制 hash 在采样前写入 `protocol.json`。只保留四条固定 T=1 槽位为后验样本，
合计 100000 个正式状态；热链不合并进诊断。全部温度预热、初始化和起点检查均计费。

这些是当前样本的观测比例，不是已验收的最终层数概率。K=1 正式冷链未访问，
继续保留 `constant_chain`，不能把零访问当作精确零后验概率，也不从验收中静默删除 K=1。
冷链各自完成 168/156/170/152 次 K=2→4→2 往返；不是 K=1→4→1 往返，
也不是独立样本数。31 点深度网格仍有 13 点未达标：最差 R-hat 在 0.667 km，
最低 bulk ESS 在 1.667 km，最低 tail ESS 在 1.833 km。

因此 `visited_K_mixing_passed=true` 仅表示已访问层数的子集通过，
`depth_mixing_passed=false`、`mixing_passed=false`、`accepted=false`。
没有调整原来的门槛来放行。

## 第 0 组最热链暴露的新问题

第 0 梯的 T=4↔8 在正式期尝试 1250 次，**接受 0 次**；四个副本均未完成冷→热→冷往返。
另三梯该对交换率约 54.5%–56.9%，每副本往返 54–69 次。
第 0 梯较低的两个相邻温度对仍有约 57.5%/58.2% 的交换率，不能只报整体平均接受率。

该异常 T=8 链的原始 log likelihood 中位数 −103.99，范围 −198.69 至 −78.77；
同梯 T=4 中位数 23.26。T=8 的表层 Vs 中位数 2.667 km/s、半空间约 1.812 km/s，
不同于其他热链表层约 0.98–1.00 km/s 的状态。它仍在 K=3/4 间活动，
所以不是所有动作都拒绝；更像停留在另一类拟合较差的结构区域。
这只是轨迹证据，尚未独立排除模态/正演分支问题。

该相邻对实际交换 log 接受比的最大值也只有 −10.91，中位数 −15.83，
对应每次接受概率至多约 1.83e-5。这解释了零交换，与保存的接受比公式一致。
不把此现象直接归因于“温度间隔过大”，也不据此立即加密温度或重置热链。

## 正演失败与核查范围

正式期所有温度共 18389 次 `forward_failure`，无 `numerical_failure`；预热另有 1597 次。
冷链本身是 3520/92813≈3.79%，全温度变差主要受热链影响，不能混淆两种分母。
第 0 梯 T=8 正式期为 5939/21141≈28.09%，是需要优先审查的具体对象。
全部失败模型均保存了 12 个观测状态；非有效观测状态为 `missing_or_unresolved`，
不能在没有独立证据时改称纯物理缺模态或已证明的漏根。

本轮没有修改生产内核。RJ 定向 CTest 7/7 通过；核查包括：

- 400000 个各温度正式模型的可变维数格式、支持域、归一化跨维先验。
- 440000 次局部转换、交换前后缓存、模型身份、拒绝后的状态保持、评估次数与失败编号。
- 独立重建 102344 次可检查的已接受局部转换的 log 接受比，包含 birth/death Hastings 因子与未加温先验。
- 四梯×四温度×三个时间点，共 48 个保留模型重算正演和归一化似然，最大误差 1.93e-10。
- 独立按分段区间重算全部深度诊断和层数指示量诊断。

这些核查支持交换/缓存和统计计算一致，不证明异常热链的模态识别或正演全域可靠性。

## 收尾与下一项

保留 PT 为有收益的可选路径，不将本轮输出标为可靠生产后验。本轮到此停止。
下一项若继续，优先对第 0 梯 T=8 的少量代表性保留/失败模型做独立根与模态核查，
