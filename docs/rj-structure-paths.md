# 两类 K=4 结构与切换路径

**本轮不直接开发界面重排提议。** 已有证据显示：两类模型确有物理剖面差异，却能产生相近的
频散预测；原跨维链已经通过K=3连接它们。固定K=4的局部对照切断了这条主要通道，
不能据此认定完整RJMCMC必须增加另一套重排算法。

对于当前“能否恢复低速夹层、解释这组数据”的目标，建议停止继续深入采样器机制，
把额外分层作为非唯一性报告。完整后验仍未验收，不据此认证精确层数/结构概率。

## 比较对象与边界

分析三个已有正式实验：低速层跨维生产链、固定K=4独立联合更新、固定K=4局部相关更新。
不新增采样、不做新正演、不改变配置，不将三个不同实验的样本合并估计概率。

沿用内部层比两侧邻层均低至少0.1 km/s的低速层定义：

- A类：K=4，最强低速层是第一个内部层，剩余界面位于它下方。
- B类：K=4，最强低速层是第二个内部层，剩余界面位于它上方。
- 无满足阈值的K=4状态单独标记；K=1/2/3也保留，不强行归入A/B。

这是描述标签，不是已经证明互不连通的后验模态。位置和剖面统计条件于标签，保留重复状态，
不对筛选后的不连续序列计算R-hat，也不以条件均值相近来认证收敛。

## 1. 不是简单改层编号，但拟合质量接近

以下数值来自原跨维实验的冷链，固定K=4两组另列在完整统计中：

| 指标 | A：额外界面在下方 | B：额外界面在上方 |
|---|---:|---:|
| 正式冷状态数 | 58783 | 6344 |
| logL中位数 | 25.617 | 25.566 |
| logL的2.5–97.5%区间 | [21.187,27.625] | [21.129,27.397] |
| 夹层顶部中位数 km | 0.784 | 0.880 |
| 夹层底部中位数 km | 1.709 | 2.053 |
| 夹层Vs中位数 km/s | 0.966 | 1.056 |
| 额外界面深度中位数 km | 2.952 | 0.470 |
| 额外界面绝对速度跳变中位数 km/s | 0.362 | 0.313 |

额外界面的速度跳变并非普遍接近零，两类剖面的浅部和深部形状也不同，
所以不能当作同一物理模型的纯编号置换。低速层的位置、速度会随额外分层一起补偿。
不过其似然分布高度重叠：当前数据拟合并没有明显偏好其中一类。

固定局部更新组的B类状态更集中于一条链：四链计数280、0、10207、149。
该组B类logL中位数较高，不能因此选它作为“更正确”的结构；其结构权重本来就未混合好。

## 2. 实际主要通过 K=3 切换

路径分析跟随**replica身份**穿过温度交换，不把“冷温度槽位交换来一个不同模型”误算成
一次模型重排。使用全部16个replica的正式路径，记录从最后一个A/B状态到下一个相反标签
之间经过的状态类别；没有已知出发标签的初始片段不计。

| 实验 | 经过K=3 | 一步直接K=4切换 | 经K=4无低速层状态 | 合计 |
|---|---:|---:|---:|---:|
| 原跨维生产链 | **534** | 14 | 3 | 551 |
| 固定K=4独立联合 | 不允许 | 45 | 27 | 72 |
| 固定K=4局部相关 | 不允许 | 0 | 63 | 63 |

跨维链约 **96.9%** 的已观察切换经过K=3（两个方向各267次）。
最常见的机制是先去掉额外分层，再重新加入，改变额外界面相对于低速层的位置。
这说明现有birth/death已经提供了连接通道，不意味着该通道足够高效或全局混合已经通过。

一步直接K=4切换在跨维组和固定独立组中全部由独立相关联合提议完成；
局部组没有观察到这样的直接切换，只经由暂时不满足低速层阈值的状态。
这是离散保留轨迹中的路径，不是对连续提议路径能垒的测量。

路径统计覆盖所有温度，不等于冷链有效独立切换数。跨维的534次K=3桥接，
抵达另一类时位于T=1/2/4/8的次数分别为69/130/132/203；
固定局部的63次切换抵达T=1仅3次。已有结果因此不能仅靠总切换次数验收。

**对前一步判断的修正：** 固定K=4是有用的层内压力测试，但它人为去掉了原算法的重要连接通道。
局部方案在此测试中失败，不能直接推出完整跨维算法必须使用专门的重排提议。

## 3. 复用已有预测，当前频散区分较弱

只复用原跨维实验早已计算的400个等间隔冷链预测，不补抽、不做新正演。
其中A类231个、B类23个，均为有效正演；其余为K=3或无目标标签的状态。
B类四链贡献为1、5、16、1个，数量少且不均衡，不是平衡、独立的两组检验。

- 两类无噪声预测中位曲线最大差约 **0.329σ**，即0.00986 km/s。
- 12个频率上的RMS差约 **0.152σ**，即0.00457 km/s。
- 逐点95%经验区间在12个频率均有重叠。
- 所选A/B模型对观测的χ²中位数约11.27/10.05，区间明显重叠。

这支持“当前已有样本的频散预测相近”，不证明严格的预测等价；B类尾部分位数尤其不稳定。
似然仅约束残差平方和，单独看似然相近不能替代曲线比较；因此这里同时使用了已有完整预测。
没有做新频率、额外模态或独立数据的辨别力检验，也未将固定K两组的小量审计点当作平衡预测样本。

## 是否值得开发重排提议

存在机制上的动机：直接把额外分层从低速层下方转到上方，有可能缩短经K=3的路径。
但它不是简单交换编号，需要同时改变物理界面和速度，并明确可逆映射、正反选择概率与Jacobian；
仅因两类预测相近，不能跳过详细平衡，也不能假定构造出的新候选仍保持拟合。

**当前没有足够的收益依据立即实现。** 现有数据支持的主要结论仍是存在低速夹层及分层非唯一性；
精确分配两类额外结构的概率目前不是已验收结果，也不应包装成唯一结构恢复。
如果后续科学问题明确要求区分上方/下方额外界面，或精确给出其概率，再单独立项研究采样与数据辨别力。
在当前任务中先停止这条优化线，比继续增加未验证机制更合适。

### 固定的小规模预测方案

仅使用原三层算例正式冷链中的K=4状态。每条链、每一类分别按出现顺序取
`floor(j*N/8), j=0..7`位置，共A/B各32个、合计64个模型；保留重复状态，不按拟合或新预测筛选。
本次恰好没有重复物理模型，但不意味着64个独立样本。
这与上一次从400个预测缓存中得到A=231/B=23不同，本次按链和标签均衡取样，
目的是查看条件差异，不估计后验类概率，也不将均衡结果冒充原后验预测。
原链未完全混合、每类每链仅8个状态，是本次分析的主要限制。

在任何新正演前固定38个查询：

- 原12个基阶频点0.15–0.9 Hz，用于核对原始似然。
- 低频基阶：0.05、0.075、0.10、0.125 Hz。
- 高频基阶：1.1、1.4、1.8、2.3、3.0、4.0 Hz。
- mode=1、mode=2各取0.3、0.45、0.6、0.9、1.2、1.8、2.5、3.5 Hz。

各模型保持Vp/Vs=1.8、密度2.3，使用冻结二进制、refined根精度，不计算梯度。
另计算一次目标模型作对照。假设新增观测的独立噪声均为σ=0.03 km/s；
这只是筛查条件，尚未验证真实高阶模态的拾取误差、可观测性或跨频率噪声相关性。

只有64个模型及目标在某查询均返回valid，才计算该点完整样本的区间和差异。
任何missing_or_unresolved都保留并停用该点评分，不剔除失败模型、不补抽，
也不把缺失状态解释为确定的物理模态截止或直接的结构证据。

### 同时比较噪声与类内分散

记中位数差绝对值为Δ，两类样本方差为s²_A、s²_B。描述指标为：

- 噪声单位差异：Δ/σ。
- 分散校正差异：D = Δ / sqrt((s²_A+s²_B)/2 + σ²)。

D不是显著性检验、分类准确率或信息增益。预先定义单点候选为Δ/σ≥1、D≥1、
且四条链各自中位数差同号；只有同一新增频段内两个相邻查询都通过，才建议进入新增数据反演。
这是本次保守筛查规则，不是物理必要条件；不因看到孤立峰值而改阈值或加密频率。

| 查询组 | 完整有效点 / 总点 | 最大Δ/σ | 最大D | 单点候选 |
|---|---:|---:|---:|---|
| 原基阶 | 12/12 | 0.341 | 0.264 | 不参与新增选择 |
| 低频基阶 | 4/4 | 0.398 | 0.193 | 无 |
| 高频基阶 | 6/6 | 1.102 | 0.460 | 无 |
| 第一高阶mode=1 | 7/8 | 4.528 | 1.370 | 0.6 Hz |
| 第二高阶mode=2 | 5/8 | 1.192 | 0.761 | 无 |

表中两个最大值分别计算，不要求来自同一个频点。
0.6 Hz处A/B中位数为1.7385/1.8744 km/s，差0.13584 km/s；
四链A−B的中位数差分别为−0.1095、−0.2005、−0.0446、−0.1706 km/s。
A/B逐点95%经验区间分别为[1.5422,1.9975]和[1.7781,1.9542] km/s，仍有明显重叠。
相邻0.45与0.9 Hz的D仅0.781和0.492，没有达到成对频点规则。
单纯增加基阶覆盖时，差异相对于类内分散较小，不能只按某点超过1σ就认为能区分。

共4个查询未完整有效：mode=1的0.3 Hz有2/65个missing_or_unresolved；
mode=2的0.3、0.45、0.6 Hz分别有65、60、32个。合计159/2470个查询状态未解析或缺失。
其余34个查询完整有效。成功状态也未经新的独立根扫描认证，保留根完整性限制。

### 成本、核查与停止判断

本轮只执行65次模型正演调用，共2470个频率/模态查询，新增采样0。
逐个核对64个原链来源、类别、均衡选取索引，以及65份物理模型；
独立用排序插值、显式样本方差重算区间、差异指标、四链方向与候选规则，全部一致。
原12点重建似然与保留值最大差6.17e−11，输入hash保持不变。

执行中命令日志的独占创建方式在第二个已完成正演后报错，修正日志更新后从剩余模型继续，
没有重跑已完成正演；随后修正了终端摘要的NumPy整数序列化，重做的仅是分析。
两次工具层问题不改变选样、查询或阈值。第二个模型的耗时未保存，因此不报告完整墙钟效率。
原脚本、修订脚本及恢复记录保留在输出目录。

当前决策：保留第一高阶0.6 Hz为后续假设，**本轮不追加频点、不生成新观测、不启动新链**。
若未来确实需要区分这两类额外分层，再围绕该窄频段做独立样本与模态可观测性检查；
本次筛查不推翻此前按结构非唯一性收尾的结论。
