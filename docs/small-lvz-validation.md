# 独立六层低速模型：一次固定配置验证

**采样与数值核查通过，但局部结构恢复仍有不确定性。** LM 与 NUTS 中位数最大差仅
0.00210 km/s；前两层真值落在各自逐层 95% 后验区间之外，低速层存在的后验概率约 83.7%。
这组结果保留原样，不调整先验、频率、初值或噪声来追齐真值。

## 试验定义

这是区别于原地壳算例的新合成模型。合成与反演使用相同的固定层界面和 Brocher05 Vp/ρ 关系，
使用同一正演程序，因此是匹配模型假设下的流程一致性检查，不是独立求解器验证。
最后一层为半空间，图中只显示至 35 km。

| 深度 km | 目标 Vs km/s | 参考 Vs km/s |
|---|---:|---:|
| 0–2 | 2.80 | 2.90 |
| 2–5 | 3.30 | 3.15 |
| 5–9 | 3.05 | 3.35 |
| 9–15 | 3.65 | 3.65 |
| 15–25 | 4.00 | 3.95 |
| ≥25 | 4.40 | 4.30 |

- 36 个基阶 Rayleigh 相速度点，频率在 0.03–0.5 Hz 对数均匀分布。未使用高阶模态，不能外推为多模态验证。
- 精细根精度的目标正演加独立高斯噪声，已知 σ=0.02 km/s，协方差为对角阵。
  NumPy 噪声 seed=2026102401；本次实际噪声 RMS=0.02260 km/s。没有重新抽噪声。
- 独立物理 Vs 截断高斯先验，中心为平滑递增参考，σ=0.1 km/s；边界参考±0.6。
  低速层目标距参考中心为 −3σ，先验偏好弱低速对比是本试验解释的一部分。
  这不是从先验抽取真值的校准试验。
- LM λ=100 的参考阻尼与 NUTS σ=0.1 对应同一惩罚。两者共用四个预定初值：参考±0.15、
  参考加按层编号变化的振幅 0.15 正弦/余弦扰动；不使用 LM 解启动 NUTS。
- 沿用 slice、目标接受率 0.95、合理步长搜索、标准 dense 适应及每个起点的 GN 初始矩阵。
  seed=20261024，每链 1000 预热＋1000 正式状态。四个数值进程，每链 600 秒硬上限，无重试或延长。
- 预先规定四链诊断 R-hat≤1.01、bulk/tail ESS≥400，正式无发散、数值失败或树深截断。
  同时检查低速对比 Vs[2]−Vs[1]，每链第 500 个零基正式状态做两尺度导数核查，
  每链 100 个状态做后验预测。预测工具 seed=20261024。

## 运行与数值验收

四链耗时 8.53 / 7.53 / 7.58 / 7.48 秒，全部一次完成；这是采样子进程耗时，不包含后续核查与绘图。
不能把它与 45 层、125 个多模态观测的原算例相比来宣称算法提速。

含六个 Vs、厚度平均速度、参考惩罚和低速对比，最大 R-hat=1.00302，最低 bulk/tail ESS=
2493.5/2404.3。正式期发散、数值失败、支持域拒绝和树深截断全部为 0。
预热发散为 7/6/8/6，链 2 预热出现 1 次数值失败；这些记录完整保留，没有丢弃链。

正式期平均每状态 7.06 次目标/梯度评估，四链合计 28242 次；包含预热、步长搜索、预检和
初始 GN 的总评估为 57709 次。这些计数不是单个频率的正演次数。

LM 四起点均收敛到同一解，终值最大差 1.6×10⁻⁸ km/s；图中按目标函数最小值选取 run 1，
所有四次结果保留。LM 与预定四个后验状态的导数核查通过；400 个后验预测状态全部有效。
独立核对了噪声重现、输入哈希、链配置、正式步长冻结、调用数和分位数，见
[核查结果](../results/small-lvz-validation/independent-audit.json)。生产内核未修改。

## 科学结果与限制

| 深度 km | 目标 Vs | LM | NUTS 中位数 | 逐层 95% 区间 |
|---|---:|---:|---:|---|
| 0–2 | 2.800 | 2.925 | 2.927 | [2.824, 3.032] |
| 2–5 | 3.300 | 3.165 | 3.164 | [3.061, 3.269] |
| 5–9 | 3.050 | 3.078 | 3.080 | [3.003, 3.161] |
| 9–15 | 3.650 | 3.563 | 3.563 | [3.457, 3.680] |
| 15–25 | 4.000 | 4.055 | 4.054 | [3.972, 4.143] |
| ≥25 | 4.400 | 4.407 | 4.406 | [4.383, 4.430] |

速度单位 km/s。各层后验/先验标准差比约为 0.546、0.534、0.406、0.579、0.443、0.124；
本算例半空间参数约束较强，不能概括为所有问题深部都弱约束。
所有保存样本距各层边界均超过 0.05 km/s，当前结果没有之前算例那种边界邻域聚集迹象。

LM 拟合 RMS=0.02060 km/s，NUTS 后验平均预测 RMS=0.02060 km/s，均与已知噪声同量级。
含噪声的逐点 95% 预测区间覆盖 34/36 个观测；这是使用同一数据拟合后的预测检查，不能当作独立测试评分。

目标低速对比 Vs[2]−Vs[1]=−0.250 km/s；后验中位数约 −0.0848，95% 区间
[−0.2469, 0.0814] km/s，跨过零，P(Vs[2]<Vs[1])=83.7%。因此中位数显示低速层，
但数据与当前先验下不能强断言其相邻层对比幅度已准确恢复。

前两层真值不在逐层 95% 区间内，六层中四层包含真值。不能把“4/6”解释为可信区间覆盖率：
这是一次固定真值、一次噪声实现，层间相关且区间不是联合置信带。匹配物理设定只消除了原算例的一类
模型不一致，仍有噪声、有限数据约束和参考先验影响；本次没有对这些偏差作因果分解。

本轮到此结束，不扫描先验、不重抽噪声、不继续追加采样。结论支持推荐配置在这个小模型上的
采样可用性；不证明一般覆盖率、所有局部结构恢复准确或任意初值下都高效。

## 复现与只读更新

在仓库根目录，使用新的输出目录运行一次完整试验：

```sh
MPLCONFIGDIR=/tmp/dw-matplotlib python scripts/benchmark_small_lvz.py \
  --exe build/dispweave --output results/small-lvz-validation-new
```

仅从已保存结果重绘一张图，不重新正演或采样：

```sh
MPLCONFIGDIR=/tmp/dw-matplotlib python scripts/benchmark_small_lvz.py \
  --output results/small-lvz-validation --plot-only
```

本次运行脚本快照保存在结果目录；后续对绘图作了层顶阶梯显示与曲线可辨识性修正，
没有改变样本、模型、观测或验收统计。生成结果按项目约定留在本地，不提交到 Git，也不发布网页。
