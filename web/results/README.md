# 本地研究结果网页

直接用浏览器打开本目录的 `index.html`。不需要安装依赖、启动后端或联网。
网页保持在项目内，通过相对路径读取 `../../results/` 的 PNG/PDF 和 `../../docs/` 的报告。
仅复制本目录到其他位置会丢失这些资源。

如偏好 HTTP 查看，在项目根目录运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory .
```

然后打开 `http://127.0.0.1:8000/web/results/`，结束时按 Ctrl+C 停止服务。
本页没有注册或发布远程站点，没有外部字体、CDN、分析统计或网络 API。

## 维护

`index.html` 保存中文研究摘要，`app.js` 保存图集元数据、已计算的截止点和浏览交互，
`styles.css` 提供响应式及打印样式。更新快照时应同步日期、结果基线、摘要、截止数据和原报告，
并保留图上及页面中的“地壳后验未通过”标记，直到新的科学验收实际通过。

本项仅新增展示层，未修改数值程序或重跑反演。页面中的 72/72 是基线核查的 CTest 记录，
不是网页测试数量。
