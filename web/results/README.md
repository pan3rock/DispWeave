# 本地结果页

直接用浏览器打开 `index.html`，无需构建、联网或 JavaScript，不发布站点。

模型图以深绿色实线表示 target、洋红虚线表示 LM、蓝色实线表示 NUTS 中位数，95% 区间填充 alpha=0.10；
颜色及线型同时区分重合曲线。

页面主区仅三张图：

1. 合成目标、参考、LM 与最新 NUTS 的中位数及逐点 95% 区间。
2. NUTS 四模态预测、观测和标准化残差。
3. 原始合成数据与目标、参考、LM 预测。

当前显示 `nuts-original-095-search`：四链各 1000 正式状态，完整验收通过。
推荐配置、观测、协方差与运行命令可从页面直接打开；使用说明见
[推荐配置与复现](../../docs/nuts-recommended-use.md)。
采样轨迹、先验／后验、相关性、效率图和原 0.99 后验保留在折叠的补充区。

## 更新

已有图更新后刷新页面即可；无需重建网页。结果目录改变时只需修改图片路径和摘要。
需要重绘最新结果及准备配置包时，运行 `scripts/refresh_crust_results.py`；该脚本只读取
已验收样本、已保存预测及目标对照缓存，不调用正演或采样。

生成文件保存在忽略的 `results/` 中，需保留项目目录结构；新克隆需恢复冻结输入及结果。
页面不嵌入所有大图，避免每次更新网页都重新打包。

如果需要 HTTP 查看，从项目根目录执行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory .
```

打开 `http://127.0.0.1:8000/web/results/`，结束时 Ctrl+C。
